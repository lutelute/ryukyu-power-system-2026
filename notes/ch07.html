まず直感で（3 分でつかむ）

📌 一言でいうと：短絡中に貯まった加速エネルギーを、事故除去後の減速エネルギーで吐き出しきれれば同期は保たれる。

🪄 たとえ話：ゴム紐でつながれた台車

台車とゴム紐 同期発電機
壁にゴム紐でつないだ台車を 押し続ける 押す力＝機械入力 P_m（タービン）
ゴムが切れた瞬間、台車は 加速 する ゴムの張力＝電気出力 P_max sinδ
ゴムを戻すと 引き戻される 切れる＝短絡事故（P_e = 0）
引き戻せる範囲を越えると伸びきる 伸びきる＝脱調（δ > δ_max）
戻すのが遅いほど台車は速い 戻す遅さ＝故障除去時間 t_c

崩れる点：ゴムの張力は伸びに比例して増え続けるが、同期化力は sinδ なので 90° を過ぎると弱くなる。だから「戻れない角度」が存在する。

📰 事例：1996年8月10日 米国西部大停電 猛暑で送電線が熱で弛み、樹木に接触して停止した。潮流の移動で発電機が 脱調 し、西部系統が 4 つに分裂して約 750 万戸が停電した。相差角が戻れない領域に入った典型例である。

📰 事例：北海道 2018 との違い 北海道ブラックアウトは「周波数」が落ちて止まった事故（第8回）。今日の同期安定度は「相差角 δ」が開きすぎて発電機同士の歩調が崩れる事故である。時間スケールは 0.1〜数秒で、保護リレーの整定が勝負を決める。

🤔 この回の式で読むと：同じ「大停電」でも機序が違う。安定度の 3 分類（同期・電圧・周波数）を最初に区別させる。

🤔 なぜ δ_cr は H に依らないのか 等面積法はエネルギーの釣り合いで、面積は P–δ 平面の幾何だけで決まる。H は「その角度に何秒で着くか」にしか関わらない。

🤔 なぜ t_cr は √H に比例するのか 事故中は加速電力が一定なので等加速度運動。δ − δ₀ = (ω₀P_m/4H)t² となり、同じ角度に達する時間は √H に比例する。H が半分なら 0.707 倍。

⚠ 落とし穴 角度を度のまま代入しない。δ はラジアン、ω₀ = 2π×60 = 377 rad/s。

この回の地図：Ⅰ 安定度の 3 分類と時間スケール → Ⅱ 動揺方程式 — 回転体の運動方程式（H の意味） → Ⅲ 等面積法 — 臨界除去角と臨界除去時間 → Ⅳ 対策と、再エネによる慣性低下

7.1 導入

学習目標

  1. 電力系統の安定度を3 分類（同期・電圧・周波数）でき、それぞれの時間スケールを言える。
  2. 動揺方程式を導出し、その物理的意味（回転体の運動方程式）を説明できる。
  3. 等面積法により臨界故障除去角・臨界故障除去時間を求められる。
  4. 安定度向上対策（PSS、FACTS、高速再閉路）の原理を説明できる。
  5. 再エネ大量導入による慣性低下が安定度に与える影響を論じられる。

前提知識（第3〜6回との接続）

第3回で導いた P=Pmaxsin⁡δP = P_\text{max}\sin\deltaP=Pmax​sinδ が今回の主役になる。 潮流計算（第4〜6回）は定常状態の計算だったが、 今回は事故発生から数秒間のダイナミクスを扱う。

7.2.4 縮約と一機無限大母線系統

実系統には数百〜数千台の発電機がある。これらを全て個別に扱うのは大変であり、 また系統全体の大まかな挙動を見るには不要である。

縮約（reduction）: 擾乱が発生したとき、多数の同期発電機は 似た動きをするグループに分かれる。その動きを少数の発電機でまとめて表すことを縮約という。

一機無限大母線系統: 縮約の極限として、 注目する 1 台の発電機と、それ以外の系統全体を「電圧・周波数が一定の理想電源 （無限大母線）」とみなすモデル。電力システム解析で最もよく使われる。

      ( ~ )────nnnn──────╫╫────────nnnn──────────────●
                    X = X_d' + X_t + X_l

この単純化が正当化される条件: 注目する発電機が系統全体に比べて十分小さく、 その挙動が系統の電圧・周波数にほとんど影響しないこと。 逆に沖縄のような小規模系統では、1 台の発電機が系統全体に影響するため、 この仮定は慎重に扱う必要がある（第2回・演習問題 7-5）。

7.2.8 再エネ大量導入と慣性の低下

系統全体の慣性定数は、同期運転中の発電機の加重平均で表される。

Hsys=∑kHkSk∑kSkH_\text{sys} = \frac{\sum_k H_k S_k}{\sum_k S_k}Hsys​=∑k​Sk​∑k​Hk​Sk​​

太陽光・風力（インバータ電源）は H=0H = 0H=0 なので、 これらが増えると分母は変わらず分子だけ減り、HsysH_\text{sys}Hsys​ が下がる。

影響:

  1. tcr∝Ht_\text{cr} \propto \sqrt{H}tcr​∝H​ より、臨界故障除去時間が短くなる
  2. df/dt∝1/Hdf/dt \propto 1/Hdf/dt∝1/H より、周波数変化率が大きくなる（第8回）
  3. ロータ動揺の周波数 fosc∝Ks/Hf_\text{osc} \propto \sqrt{K_s/H}fosc​∝Ks​/H​ が上がる

対策:

  • 同期調相機: 発電しない同期機を回し、慣性だけを供給する
  • 合成慣性（synthetic inertia）: インバータが df/dtdf/dtdf/dt を検出して 瞬時に有効電力を増減し、慣性を模擬する
  • グリッドフォーミングインバータ: 電圧源として振る舞い、 同期機と同様の慣性・同期化力を提供する（第9回、第13回）
  • 蓄電池による高速周波数応答（FFR）

図 7.7　慣性定数 H と臨界除去時間の関係（左）と、電源種別の H（右）。t_cr は √H に比例するため、H が 4 → 2 s になると 247 → 175 ms（0.707 倍）に縮む。インバータ電源は回転体を持たず H = 0。

7.3.2 動揺方程式の数値積分 — 安定と不安定の分岐

"""第7回 デモ2: 故障除去時間を変えて安定/不安定を観察する"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Hiragino Sans', 'Yu Gothic', 'DejaVu Sans']

H, D, f0 = 4.0, 0.5, 60.0
w0 = 2*np.pi*f0
P_max, P_m = 2.0, 0.8
delta0 = np.arcsin(P_m/P_max)

def swing(t, y, t_clear):
    """y = [delta, omega_dev]"""
    delta, dw = y
    Pe = 0.0 if t < t_clear else P_max*np.sin(delta)   # 故障中は Pe=0
    ddelta = dw
    domega = (w0/(2*H))*(P_m - Pe - D*dw/w0)
    return [ddelta, domega]

fig, axes = plt.subplots(1, 2, figsize=(13, 5))
t_span, t_eval = (0, 5.0), np.linspace(0, 5.0, 3000)

for t_clear, color in [(0.10, "#2a9d8f"), (0.20, "#e9c46a"),
                       (0.28, "#f4a261"), (0.35, "#e63946")]:
    sol = solve_ivp(swing, t_span, [delta0, 0.0], t_eval=t_eval,
                    args=(t_clear,), rtol=1e-8, atol=1e-10, max_step=0.001)
    d_deg = np.rad2deg(sol.y[0])
    stable = d_deg.max() < 180 and np.isfinite(d_deg).all()
    label = f"$t_c$={t_clear*1000:.0f} ms " + ("(安定)" if stable else "(脱調)")
    axes[0].plot(sol.t, d_deg, color=color, lw=2, label=label)
    axes[1].plot(d_deg, sol.y[1]*60/(2*np.pi), color=color, lw=1.5, label=label)

axes[0].axhline(180, color="k", ls="--", alpha=0.6, label="180° (脱調の目安)")
axes[0].set_xlabel("時間 [s]"); axes[0].set_ylabel("相差角 $\\delta$ [deg]")
axes[0].set_title("時間応答"); axes[0].legend(fontsize=9); axes[0].grid(alpha=0.3)
axes[0].set_ylim(0, 400)

axes[1].set_xlabel("$\\delta$ [deg]"); axes[1].set_ylabel("速度偏差 [Hz]")
axes[1].set_title("位相平面（安定なら閉曲線に収束）")
axes[1].legend(fontsize=9); axes[1].grid(alpha=0.3)
axes[1].set_xlim(0, 400)

plt.tight_layout()
plt.savefig("../図/ch07_swing.png", dpi=150)

観察してほしいこと:

  • tct_ctc​ が短いうちは δ\deltaδ が振動しながら減衰し、元の運転点に戻る（安定）
  • tct_ctc​ が tcrt_\text{cr}tcr​ を超えると δ\deltaδ が単調増加して発散する（脱調）
  • 位相平面では、安定な場合は渦を巻いて収束し、不安定な場合は右へ抜けていく

7.6 まとめ

キーポイント

  • 安定度は同期・電圧・周波数の 3 分類。第7回は同期安定度を扱った。
  • 動揺方程式は回転体の運動方程式そのもの: 2Hω0d2δdt2=Pm−Pe−Ddδdt\frac{2H}{\omega_0}\frac{d^2\delta}{dt^2} = P_m - P_e - D\frac{d\delta}{dt}ω0​2H​dt2d2δ​=Pm​−Pe​−Ddtdδ​
  • 慣性定数 HHH [s] は「運動エネルギーだけで何秒発電を続けられるか」。 火力 3〜6 s、水力 2〜4 s、インバータ電源は 0 s。
  • 定態安定条件は dPe/dδ>0dP_e/d\delta > 0dPe​/dδ>0、すなわち δ<90°\delta < 90°δ<90°。 δ>90°\delta > 90°δ>90° では正のフィードバックになり脱調する。
  • 等面積法: 加速面積 A1A_1A1​ と減速面積 A2A_2A2​ が等しくなれば安定。 cos⁡δcr=PmPmax(π−2δ0)−cos⁡δ0,tcr=4H(δcr−δ0)ω0Pm\cos\delta_\text{cr} = \frac{P_m}{P_\text{max}}(\pi-2\delta_0) - \cos\delta_0, \qquad t_\text{cr} = \sqrt{\frac{4H(\delta_\text{cr}-\delta_0)}{\omega_0 P_m}}cosδcr​=Pmax​Pm​​(π−2δ0​)−cosδ0​,tcr​=ω0​Pm​4H(δcr​−δ0​)​​
  • tcr∝Ht_\text{cr} \propto \sqrt{H}tcr​∝H​。再エネ大量導入で慣性が下がると 保護に許される時間が短くなる。
  • 安定度向上対策は「A1A_1A1​ を減らす」（高速除去）か「A2A_2A2​ を増やす」（PmaxP_\text{max}Pmax​ 増）か 「制動を増やす」（PSS）のいずれか。FACTS は半導体で高速に XXX・QQQ を操作する。
