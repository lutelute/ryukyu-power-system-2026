<div class="sec">

# 導出 — キルヒホッフの電流則から I = Y_bus V

<div class="sec">
  <span class="sec-title">① 線路の電流｜母線 i から j へ I_ij = y_ij (V_i − V_j)</span>
  <span class="sec-body">線路は直列アドミタンス y_ij = 1/z_ij。両端の電圧差に比例した電流が流れる（オームの法則）。</span>
</div>

<div class="sec">
  <span class="sec-title">② 母線の収支｜注入電流 I_i = Σ_j I_ij（電流則）</span>
  <span class="sec-body">外から注入した電流は、つながる線路に全部分かれる。I_i = (Σ_j y_ij) V_i − Σ_j y_ij V_j。**V_i の係数が対角、V_j の係数が非対角**。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 並べる｜Y_ii = Σ_j y_ij + 対地分、Y_ij = −y_ij → I = Y_bus V</span>
  <span class="sec-body">全母線分を縦に並べると行列の式になる。対称（Y_ij = Y_ji）で、線路のない i–j は 0。**疎** で **対称** はここから来る。</span>
</div>

<!-- note: 段階開示。②で「V_i の係数」と「V_j の係数」を色分けして板書すると、対角と非対角の由来が見える。移相器があると対称が崩れる（本講義では扱わない）。 -->

# 導出 — S_i = V_i I_i* から P_i と Q_i へ

<div class="sec">
  <span class="sec-title">① 複素電力｜S_i = P_i + jQ_i = V_i I_i*（第3回）</span>
  <span class="sec-body">母線 i に注入する電力。I_i は Ⅰ章の I_i = Σ_j Y_ij V_j で電圧に置き換わる。</span>
</div>

<div class="sec">
  <span class="sec-title">② 代入｜S_i = V_i Σ_j Y_ij* V_j*</span>
  <span class="sec-body">極形式 V_i = V_i e^{jθ_i}、Y_ij = G_ij + jB_ij を入れると S_i = Σ_j V_i V_j (G_ij − jB_ij) e^{j(θ_i − θ_j)}。**電圧の積 V_i V_j** がここで生まれる。</span>
</div>

<div class="sec">
  <span class="sec-title">③ オイラー｜e^{jθ_ij} = cos θ_ij + j sin θ_ij で実部と虚部に分ける</span>
  <span class="sec-body">P_i = V_i Σ_j V_j (G_ij cos θ_ij + B_ij sin θ_ij)、Q_i = V_i Σ_j V_j (G_ij sin θ_ij − B_ij cos θ_ij)。母線ごとに **P の式と Q の式が 1 本ずつ**。</span>
</div>

<!-- note: 段階開示。②の共役で Y_ij* = G − jB になる符号に注意。③は板書で 1 行ずつ。2 母線・無損失にすると第3回の P = V_sV_r sinδ/X に戻ることを確認させる。 -->

---

<!-- _class: equation -->

# 電力方程式 — 母線ごとに P と Q が 1 本ずつ

<div class="eq-main">

$$P_i = V_i \sum_{j} V_j\,(G_{ij}\cos\theta_{ij} + B_{ij}\sin\theta_{ij}), \quad Q_i = V_i \sum_{j} V_j\,(G_{ij}\sin\theta_{ij} - B_{ij}\cos\theta_{ij})$$

</div>

<div class="eq-desc">
  <span class="sym">$G_{ij} + jB_{ij}$</span>
  <span>Y_bus の要素。配線の情報はここに全部入っている</span>
  <span class="sym">$\theta_{ij}$</span>
  <span>θ_i − θ_j。母線間の位相差。P を運ぶのはこれ（第3回）</span>
  <span class="sym">$V_i V_j$</span>
  <span>電圧の積。ここと cos/sin が非線形の正体</span>
  <span class="sym">$P_i, Q_i$</span>
  <span>左辺は与えられる注入電力（発電 − 負荷）。式の数は母線数 × 2</span>
</div>

<!-- note: 2 母線・G = 0・B12 = −1/X で P1 = −V1V2 sin(θ1 − θ2)/X。符号の向き（注入か流出か）を除けば第3回の式。「一般式が特殊ケースを含む」を必ず確かめさせる。 -->

# なぜスラックは 1 つ必要で、1 つで足りるのか

<div class="sec">
  <span class="sec-title">理由 1｜損失は解くまで分からない</span>
  <span class="sec-body">全母線で P を指定すると Σ P_i = 損失 を事前に満たさなければならないが、損失は解いて初めて出る（前の図の 3.71 MW）。1 つの母線だけ P を自由にして **帳尻（slack = たるみ）** を吸わせる。</span>
</div>

<div class="sec">
  <span class="sec-title">理由 2｜位相の基準が要る</span>
  <span class="sec-body">式には θ_i − θ_j の **差** しか現れない。全部に同じ定数を足しても式は変わらず、解が定まらない。1 つの母線で θ = 0 と決める。本講義ではスラックを母線 1 に取る。</span>
</div>

<div class="sec">
  <span class="sec-title">PV → PQ の切り替え｜Q の限界に当たったとき</span>
  <span class="sec-body">AVR には無効電力の限界 Q_min ≤ Q ≤ Q_max がある。超えたら Q を限界値に固定して **PQ 母線に変える**（第5回）。だから N_PV は反復の途中で減ることがある。</span>
</div>

<!-- note: 2 つのスラックを置くと損失の分担が決まらず解が一意でない。教科書はスラックノードと基準ノードを区別するが、通常は同じノード。 -->

## 3 つの近似で線形にする — 1 回解けば終わり

---

<!-- build -->

# 導出 — 3 つの近似で P = B′θ

<div class="sec">
  <span class="sec-title">近似 1｜R ≈ 0、対地アドミタンスも無視 → G = 0</span>
  <span class="sec-body">架空送電線は X/R ≈ 5〜15（第3回）。Y_bus = jB となり、P_i = V_i Σ_j V_j B_ij sin θ_ij。**cos の項（Q 側）が消える**。</span>
</div>

<div class="sec">
  <span class="sec-title">近似 2｜V_i ≈ 1.0 p.u.（正常時は 0.95〜1.05）</span>
  <span class="sec-body">電圧の積 V_i V_j が 1 になり、P_i = Σ_j B_ij sin θ_ij。**未知数は θ だけ**になる。</span>
</div>

<div class="sec">
  <span class="sec-title">近似 3｜sin θ_ij ≈ θ_ij（位相差が小さい、30° で誤差 4.7%）</span>
  <span class="sec-body">P_i = Σ_j (θ_i − θ_j)/x_ij、つまり **P = B′θ**（B′_ii = Σ 1/x_ij、B′_ij = −1/x_ij）。線形なので反復不要。直流回路の I = V/R と同じ形。</span>
</div>

<!-- note: 段階開示。「直流法」は直流送電の話ではなく、V ↔ δ、I ↔ P、R ↔ X の対応で直流回路と同じ式になるから。Q・電圧・損失は出ない。 -->

# なぜそう考えるか — 非線形・3 種類・スラック

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ非線形なのか</span>
  <span class="bk-body">与えられるのが電流ではなく電力だから。S = VI* に I = Y_bus V を入れると V の積と cos/sin が入り、連立一次方程式にならない。電流で指定できるなら潮流計算は要らない。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ母線は 3 種類なのか</span>
  <span class="bk-body">各母線は P, Q, V, θ の 4 量のうち 2 つを与える。負荷は P, Q（PQ）、AVR 付き発電機は P と V（PV）。損失は解くまで分からないので、誰かが帳尻を引き受ける（スラック：V, θ）。</span>
</div>

<div class="bk alert">
  <span class="bk-title">落とし穴</span>
  <span class="bk-body">スラック母線は 1 つだけ。2 つ置くと損失の分担が決まらず解が定まらない。位相の基準もスラックが担う。発電機があっても電圧を制御しなければ PV ではない。</span>
</div>

</div>

# 持ち帰る 3 点

<div class="ta-main">配線は Y_bus、需給は電力方程式。未知数 N_PV + 2N_PQ を反復で解くのが潮流計算</div>

<div class="ta-points">
<li>Y_ii = Σ y_ij、Y_ij = −y_ij。対称で疎（IEEE 118 で 3.4%）。線路 1 本で 4 か所更新</li>
<li>母線は 4 量のうち 2 つを与える。スラックは 1 つだけで損失と位相基準を引き受ける</li>
<li>直流法：G = 0、V = 1、sin θ ≈ θ。P = B′θ を 1 回解く。ずれは数 MW、Q と損失は出ない</li>
</div>
