## 参考教科書

**加藤・田岡『電力システム工学の基礎』**（全7章・114ページ）を正本とし、
**用語・記号・例題をこの教科書に準拠**させている。学生が教科書で予復習できるよう、
各回の冒頭に対応する章・節を明示した。

- 教科書がカバーする範囲: **第1〜8回**（電力システム／交流回路／送電系統／潮流計算／
  安定度計算／電圧の特性／周波数の特性）
- 教科書がカバーしない範囲: **第9〜15回**（インバーター、気象・需要予測、AI 応用、総合演習）
  — 本講義の独自部分

用語・記号の対応、教科書から取り込んだ項目の一覧は
[`教科書対応.md`](教科書対応.md) にまとめてある。**受講前に必ず目を通すこと。**

## 講義ポータル（読む → 見る → 解く）

`index.html` を開くと、各回に **📖 ノート／🖥 動く図／✍ 演習** の 3 つが並ぶ。
サーバー不要、ダブルクリックで動く（file:// で完結。数式は同梱の KaTeX で描画、外部通信なし）。

| 種類 | 場所 | 内容 |
|:--|:--|:--|
| 📖 ノート | `notes/chNN.html`（原稿は `ノート/*.md`） | 教科書準拠の本文。理論・例題・Python に加え、事例（📰）・たとえ話（🪄）・なぜそう考えるか（🤔）・実務でどう効くか |
| 🖥 動く図 | `viz/*.html` | 各回の核心 1 つを実計算で追う（process_nn 形式、下表） |
| ✍ 演習 | `ex/chNN.html` | 学籍番号をシードに数値が変わる 5〜6 問。採点・途中式・答え。進捗はこの端末の localStorage に保存 |
| 📊 スライド | `スライド/chNN.pptx`（原稿は `スライド/chNN.md`） | 講義用 PowerPoint 各 28〜36 枚（marp-pptx、編集可能）。全体像 → 事例 → たとえ話 → 章ごとに 図で読み解く／導出を段階開示／図つき例題 → 誤解 → 持ち帰る 3 点。図はすべて `コード/fig_chNN.py` の実計算 |
| 付録 | `notes/symbols.html`, `notes/textbook.html` | 記号表・教科書対応 |

- スライド原稿 `スライド/chNN.md` を編集したら `bash tools/build-decks.sh`（`ch08` で 1 回分）で PPTX を再生成し、`node tools/sync-intuition.mjs` でノート冒頭の「まず直感で」節（一言・たとえ話・事例・なぜそう考えるか・地図）をスライドから同期する
- ノート（Markdown）を編集したら `node tools/build-notes.mjs`（`--only ch08` で 1 回分）で `notes/` を再生成する
- 演習の検証は `node tools/test-ex.mjs all`（20 シードで生成器を検査）、リンク・JS 構文は `node tools/check-pages.mjs`
- 配布用 zip は `bash tools/make-dist.sh`（試験・tools を除外し、`はじめに.txt` を同梱）

### 図とコード

各回の図は `コード/fig_chNN.py` が実計算して `図/` に出力する（1 回あたり 9〜13 枚）。
潮流計算は pandapower、動揺方程式と周波数応答は RK4、決定木・GNN・PCA・Q 学習は numpy で自作。
**スライドとノートに書かれた数値は、すべてこのスクリプトが print した実測値**である。

```bash
cd コード && python3 fig_ch08.py     # 図を再生成（末尾に数値を print）
```

### 動くインフォグラフ（process_nn 形式）

各回の核心を、ブラウザ内で**実計算しながら「次へ ▶」で追える**単一 HTML 教材にした。
形式は [process_nn](https://github.com/lutelute/process_nn) / viz-note-kit の流儀に準拠
（外部依存ゼロ・シード付き乱数・実計算のみ・章 4／スライド 13〜15・A/B 対比・⚠よくある誤解・用語ノート）。

- 各回: `viz/energy.html`（第1回）〜 `viz/island.html`（第15回）。各ページ上部からノート・演習へ飛べる
- 用語ノート 49 語: `viz/terms.js`、順路と note/ex の対応: `viz/site.js`
- ブラウザ検証は `python3 -m http.server 8877` でこのフォルダを配信して `index.html` を開く（file:// でも同じに動く）

| 回 | ページ | 実計算している核心 |

| 1 | energy | カルノー効率 1−T_L/T_H、風速の 3 乗則、パワーカーブ |

## 各回ノートの構成

`lecture-content-builder` スキルの章テンプレートに準拠する。

0. **まず直感で（3 分でつかむ）** — 📌 一言 ／ 🪄 たとえ話 ／ 📰 事例 2 件 ／ 🤔 なぜそう考えるか ／ この回の地図（スライドから自動同期）
1. **導入** — 学習目標／前提知識（前回との接続）
2. **理論** — 定義・定理・数式導出（ステップバイステップ）
3. **シミュレーション** — Python によるデモ（対応する MATLAB コードを参考掲載）
4. **例題** — 手計算で解ける問題 → Python で検算
5. **演習問題** — 基礎2〜3問／応用1〜2問
6. **まとめ** — キーポイントと次回への橋渡し

冒頭の引用ブロックから、その回の 🖥 動く図と ✍ 演習へ飛べる。
