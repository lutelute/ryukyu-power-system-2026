## 係数がそのまま読める

<!-- _class: equation -->

# 重回帰モデル — 構造を式にする

<div class="eq-main">

$$y_t = a + b\,\text{CDD}_t + c\,\text{HDD}_t + d\,\text{平日}_t + \sum_{k=1}^{3}\left(e_k\sin\tfrac{2\pi k t}{24} + f_k\cos\tfrac{2\pi k t}{24}\right) + \varepsilon_t$$

</div>

<div class="eq-desc">
  <span class="sym">$b, c$</span>
  <span>気温感度 [MW/°C]。b が冷房側、c が暖房側。沖縄は b ≫ c</span>
  <span class="sym">$d$</span>
  <span>平日ダミー。平日と休日の差 [MW]。係数が読めるのが重回帰の強み</span>
  <span class="sym">$e_k, f_k$</span>
  <span>フーリエ項：日内変動を滑らかに表す。k を増やすほど細かい形を表現できる</span>
  <span class="sym">$\varepsilon_t$</span>
  <span>説明できない残り。小さいほど良いが、リークで小さく見せてはいけない</span>
</div>

<!-- note: 年周期のフーリエ項も 1 組入れている。特徴量の設計そのものがモデリング。 -->

# 導出 — なぜランダム分割をしてはいけないか

<div class="sec">
  <span class="sec-title">① 時系列は隣が似ている｜自己相関が高い</span>
  <span class="sec-body">1 時間前との相関はほぼ 1。ランダムに分けると、検証データの「すぐ隣」が学習に入ってしまう。</span>
</div>

<div class="sec">
  <span class="sec-title">② それは実質的に答えを見ている｜リーク</span>
  <span class="sec-body">未来の情報が学習に混ざると、検証精度は現実より良く出る。運用に出した瞬間に精度が崩れる。</span>
</div>

<div class="sec">
  <span class="sec-title">③ だから時間順に切る｜過去で学び、未来で試す</span>
  <span class="sec-body">実測では、ランダム分割は RMSE を **41.7 → 36.1 MW** と 14% 過小に見せる。運用では出ない性能である。</span>
</div>
