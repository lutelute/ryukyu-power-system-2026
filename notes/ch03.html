まず直感で（3 分でつかむ）

📌 一言でいうと：有効電力 P は位相差 δ で、無効電力 Q は電圧の大きさの差で決まる。この分離が、潮流・電圧・安定度のすべての出発点になる。

🪄 たとえ話：ジョッキのビールと泡

ジョッキ 電力
ジョッキの容量が決まっている 容量＝皮相電力 S =
飲めるのは ビール の分だけ ビール＝有効電力 P（仕事をする）
泡 は飲めないが容量を占める 泡＝無効電力 Q（磁界を往復する）
泡が多いと注ぐ管を太くする必要 管を太く＝電流が増え損失が増える
ビールの割合＝ジョッキの「実力」 割合＝力率 cos φ = P/S

崩れる点：泡は捨ててよいが Q は捨てられない。モータや変圧器の磁界は Q が無いと立たない。「役に立たない」のではなく「仕事はしないが必要」。

📰 事例：力率が電気料金を動かす 高圧で受電する工場やビルは、力率 85% を基準に基本料金が 割引・割増 される。同じ P でも Q が多いと電流が増え、送配電設備を余計に占有するから。工場がコンデンサを置くのは Q を現地で作るため。

📰 事例：夜中に電圧が上がる（フェランチ効果） 長い送電線やケーブルでは、負荷が軽い深夜に受電端の電圧が送電端より高くなる。線路の静電容量が Q を出し続けるため。分路リアクトルで吸い取らないと機器の絶縁を傷める。

🤔 この回の式で読むと：どちらも「Q が電圧を決め、電流を増やす」という今日の主張の裏返し。力率の話は「環境の話」である前に「設備と料金の話」。

🤔 なぜ単位法を使うのか ①変圧器の一次・二次の換算が不要になる ②数値が 1 前後に揃う ③機器の定数が容量によらず似た値になり（変圧器の %Z は 5〜15%）、経験で妥当性を判断できる。

🤔 なぜ P は δ で、Q は V なのか 送電線は X ≫ R。X だけの線路では、位相差が電流の「向き」を、電圧差が電流の「大きさの余り」を作る。R が大きい配電線では分離が崩れる（第6回）。

⚠ 落とし穴 三相基準（S = √3 V I）と単相基準を混ぜない。V_base は線間電圧で統一し、Z_base = V_base²/S_base で √3 が消えることを一度確かめておく。

この回の地図：Ⅰ 複素電力 S = P + jQ — 無効電力の物理的意味 → Ⅱ 送電線の R・L・C と π 型等価回路 → Ⅲ 単位法 — 変圧器を消し、数値を 1 前後に揃える → Ⅳ 2 母線の送電電力式 — P–δ と Q–V の分離

3.1 導入

学習目標

  1. 複素電力 S˙=P+jQ\dot{S} = P + jQS˙=P+jQ を定義から導出し、無効電力の物理的意味を説明できる。
  2. 送電線の線路定数 R,L,CR, L, CR,L,C の由来を説明し、π型等価回路を構成できる。
  3. 単位法で系統諸量を換算でき、その利点を3つ挙げられる。
  4. 2母線系統の送電電力式から、有効電力は位相差・無効電力は電圧差で決まることを導ける。

前提知識（第2回との接続）

第2回で、系統が多数の電圧レベルを変圧器で繋いだ階層構造であることを見た。 また、送電損失が RP2/(V2cos⁡2ϕ)RP^2/(V^2\cos^2\phi)RP2/(V2cos2ϕ) で表され、力率が効くことも確認した。

今回は、その「力率」の正体である無効電力を正面から扱い、 潮流計算に必要な回路モデルと単位法を整備する。 この回が第4〜6回の潮流計算の土台になるので、確実に理解すること。

3.2.5 単位法（パーユニット法・p.u. 法）

用語: 教科書（3.2 節）は単位法と呼ぶ。英語文献や実務では パーユニット法（per-unit method）、単位は p.u. と表記されることが多い。 本講義では教科書に従い「単位法」を使い、数値には p.u. を付す。

定義: 基準値に対する比を取る。

p.u. 値=実際の値基準値\text{p.u. 値} = \frac{\text{実際の値}}{\text{基準値}}p.u. 値=基準値実際の値​

三相系統では、基準容量 SbaseS_\text{base}Sbase​（三相合計）と基準電圧 VbaseV_\text{base}Vbase​（線間） の2つを選ぶと、残りが自動的に決まる。

Ibase=Sbase3 Vbase,Zbase=Vbase2SbaseI_\text{base} = \frac{S_\text{base}}{\sqrt{3}\,V_\text{base}}, \qquad \boxed{Z_\text{base} = \frac{V_\text{base}^2}{S_\text{base}}}Ibase​=3​Vbase​Sbase​​,Zbase​=Sbase​Vbase2​​​

ZbaseZ_\text{base}Zbase​ の導出: $Z_\text{base} = \dfrac{V_\text{base}/\sqrt{3}}{I_\text{base}} = \dfrac{V_\text{base}/\sqrt{3}}{S_\text{base}/(\sqrt{3}V_\text{base})} = \dfrac{V_\text{base}^2}{S_\text{base}}$ （3\sqrt{3}3​ が消えるのがポイント。相電圧と線間電圧を混同しないこと）

利点（3つ）:

  1. 変圧器のインピーダンス換算が不要になる。 基準電圧を変圧器の巻数比に合わせて取れば、一次側・二次側で p.u. 値が一致する。 第2回の MATLAB 例で確認したとおり。
  2. 数値が 1 前後に揃う。 電圧は 0.95〜1.05、インピーダンスは 0.01〜0.5 程度。 桁違いの数値が混ざらないので、数値計算の条件数が改善し、異常値に気づきやすい。
  3. 機器容量によらず値の範囲が決まる。 変圧器の %Z は容量に関係なく 5〜15%、 発電機の Xd′X_d'Xd′​ は 0.15〜0.35 p.u.。値を見れば妥当性が判断できる。

有効電力 PPP 位相差 δ\deltaδ 位相を進めると PPP が流れ出す
無効電力 QQQ 電圧の大きさの差 電圧が高い側から低い側へ流れる

実際、δ\deltaδ が小さいとき sin⁡δ≈δ\sin\delta \approx \deltasinδ≈δ、cos⁡δ≈1\cos\delta \approx 1cosδ≈1 だから

P≈VsVrXδ,Q≈Vr(Vs−Vr)XP \approx \frac{V_sV_r}{X}\delta, \qquad Q \approx \frac{V_r(V_s - V_r)}{X}P≈XVs​Vr​​δ,Q≈XVr​(Vs​−Vr​)​

この P-δ / Q-V 分離（デカップリング）が、

  • 第5回の高速デカップル法（ヤコビアンを分離して高速化）
  • 第7回の安定度（P=Pmaxsin⁡δP = P_\text{max}\sin\deltaP=Pmax​sinδ の電力相差角曲線）
  • 第8回の周波数制御（PPP 不足 → 周波数低下）と電圧制御（QQQ 不足 → 電圧低下）

のすべての出発点になる。この式は暗記すること。

また、PPP は δ=90°\delta = 90°δ=90° で最大値 Pmax=VsVr/XP_\text{max} = V_sV_r/XPmax​=Vs​Vr​/X を取る。 これを超えると同期を保てない（定態安定限界、第7回）。

3.6 まとめ

キーポイント

  • 複素電力 S˙=V˙I˙∗=P+jQ\dot{S} = \dot{V}\dot{I}^* = P + jQS˙=V˙I˙∗=P+jQ。 PPP は正味運ばれるエネルギー、QQQ は電源と負荷を往復するだけ。 しかし QQQ も線路に電流として流れるので損失を生む。
  • 力率が下がると同じ PPP に対して電流が増え、損失は cos⁡2ϕ\cos^2\phicos2ϕ に反比例して増える。
  • 送電線は R,L,CR, L, CR,L,C で表され、中距離ではπ型等価回路を用いる。 架空線では X/R≈5∼15X/R \approx 5\sim15X/R≈5∼15 でリアクタンス支配的。
  • 単位法の3つの利点: ①変圧器の換算が不要、②数値が 1 前後に揃う、 ③機器容量によらず値の範囲が決まり妥当性を判断できる。
  • 本講義で最も重要な式: P=VsVrXsin⁡δ,Q=VsVrcos⁡δ−Vr2XP = \frac{V_sV_r}{X}\sin\delta, \qquad Q = \frac{V_sV_r\cos\delta - V_r^2}{X}P=XVs​Vr​​sinδ,Q=XVs​Vr​cosδ−Vr2​​ → 有効電力は位相差 δ\deltaδ、無効電力は電圧の大きさの差が支配する。 この P-δ / Q-V 分離が第5回・第7回・第8回すべての基礎になる。
  • PPP は δ=90°\delta = 90°δ=90° で最大 Pmax=VsVr/XP_\text{max} = V_sV_r/XPmax​=Vs​Vr​/X。これが定態安定限界。
