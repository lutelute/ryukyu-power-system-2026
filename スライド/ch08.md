# 速度調定率 ε — ガバナの傾き

## 読み方｜横軸が出力、縦軸が周波数。直線の傾きが「何 Hz で何 MW 動くか」

![w:600](../図/ch08_droop.png)

<div class="fs-points">
- ε は無負荷と全負荷の周波数差の割合
- ε = 5%、定格 300 MW なら K_G = **100 MW/Hz**
- 0.2 Hz 下がると出力 +20 MW
- ε が小さいほど傾きが急＝よく効く
</div>

<div class="fs-conclusion">ε が小さすぎると出力が激しく動いて機器を痛める。4〜5% はその妥協点である。</div>

# 交点が運転点 — 発電特性と負荷特性

## 読み方｜2 本の直線の交点が周波数。発電特性が左へずれると交点が下がる

![w:600](../図/ch08_intersection.png)

<div class="fs-points">
- K = K_G + K_L = **150 MW/Hz**（沖縄）

# 単位の約束 — %MW/0.1Hz を MW/Hz に直す

# LFC の積分ゲイン — 大きすぎても小さすぎても

## 読み方｜β は「偏差をどれだけ急いで消すか」。行き過ぎると振動する

![w:620](../図/ch08_lfc_gain.png)

<div class="fs-points">
- β 小：戻りが遅く偏差が長く残る
- β 適正：滑らかに 60 Hz へ
- β 大：行き過ぎて **振動**
- 教科書 例題7.3 の主張と同じ
</div>

<div class="fs-conclusion">制御ゲインは速さと安定性のトレードオフ。ここは制御工学そのもので、系統に固有の話ではない。</div>

# なぜそう考えるか — 単位・符号・役割

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ %MW/0.1Hz なのか</span>
  <span class="bk-body">運用で扱う周波数偏差は 0.1 Hz 程度。1 Hz 基準だと現場の数字が小さくなりすぎる。K [MW/Hz] = %K × S / 10 と覚える。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ「発電余剰を正」にするのか</span>
  <span class="bk-body">ΔP と ΔF の符号が揃い、ΔP = KΔF の K が正の定数になる。発電機脱落は ΔP が負、周波数低下も負で、式が 1 本で済む。</span>
</div>

<div class="bk alert">
  <span class="bk-title">H と K は役割が違う</span>
  <span class="bk-body">H は落ち方の速さと最低点、K は最終的にどこで止まるか。両方が要る。</span>
</div>

# 持ち帰る 3 点

<div class="ta-main">周波数のずれは ΔP ÷ K。小さい系統・少ない慣性ほど、同じ事故で大きく速く落ちる</div>

<div class="ta-points">
<li>K = %K × S / 10 [MW/Hz]。単位の 10 倍の罠に注意</li>
<li>慣性 → ガバナ → LFC の順に効く。RoCoF は H に反比例</li>
<li>連系線は周波数の応援線。沖縄は自分の K と H だけで守る</li>
