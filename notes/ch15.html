まず直感で（3 分でつかむ）

📌 一言でいうと：沖縄本島に太陽光を何 MW まで入れられるか。答えは 6 つの上限の最小値で決まり、対策は「今の律速」に打つ。

🪄 たとえ話：樽の一番低い板

樽 連系可能量
樽に入る水は 一番低い板 で決まる 連系可能量 = min(6 つの上限)
高い板を伸ばしても水は増えない 律速でない制約への対策は無駄
低い板を伸ばすと 次に低い板 が効く 対策すると 律速が移る
板は 6 枚 電圧・容量・N-1・周波数・安定度・最低出力
1 枚を伸ばす道具が別の板も伸ばすことがある 蓄電池は周波数と最低出力の 2 枚 を伸ばす

崩れる点：板は独立だが制約は連動する。太陽光を増やすと同期機が減り、周波数と安定度の板が同時に下がる。

📰 事例：2018年 北海道ブラックアウトの教訓 大型電源への依存、系統の小ささ、そして 応援が来ない こと。北海道は本州との直流連系が細く、沖縄は連系そのものが無い。周波数と慣性の議論（第8回）は、沖縄では設計の前提になる。

📰 事例：離島の実証と、本島の制約 宮古島などの離島では再エネと蓄電池を組み合わせた実証が行われてきた。本島は 60 Hz の独立系統で、太陽光の拡大とともに火力の最低出力と慣性が制約として前に出てきている。今日の 6 制約はこの現実を式にしたもの。

🤔 この回の式で読むと：沖縄は「日本で最も再エネ統合が難しい系統の 1 つ」。だからこそ教材として面白い。

🤔 なぜ最小値なのか 制約は「すべて満たす」もの。1 つでも破れば運用できないので、上限の集合の最小値が答えになる。

🤔 なぜ対策で律速が移るのか 対策は特定の板だけを伸ばす。伸ばした板が最小でなくなった瞬間、次に低い板が答えを決める。投資の順番は「今の律速」で決まる。

⚠ 1 つの制約だけ見ない 電圧が余裕でも周波数で入らない。系統計画は 6 枚の板を同時に見る仕事である。

この回の地図：Ⅰ 系統モデルと 6 つの制約 → Ⅱ 制約ごとに「どこで破れるか」を実計算する → Ⅲ 最小値を取り、律速を言う → Ⅳ 対策を打つと律速が移る — 投資の順番

15.1 導入

学習目標

  1. 実系統を模したモデルを構築し、潮流計算 → 安定度評価 → 予測 → 最適化を 一連の流れとして実行できる。
  2. N-1 事故解析を実施し、系統の健全性を評価できる。
  3. 再生可能エネルギーの導入可能量を、複数の制約から総合的に決定できる。
  4. 本講義で学んだ各回の内容が、実務でどう繋がるかを説明できる。
  5. 電力システム工学の今後の課題と研究トレンドを述べられる。

本回の課題 — 沖縄本島系統の再エネ導入可能量を評価する

「沖縄本島系統に、太陽光発電を何 MW まで導入できるか」

この一見単純な問いに答えるには、本講義のほぼ全内容が必要になる。

制約 何で決まるか 学んだ回
電圧上限 逆潮流による電圧上昇 第3回、第6回、第9回
線路容量 潮流の過負荷 第4〜6回
N-1 基準 1 回線停止時にも耐えるか 第2回、第15回
同期安定度 慣性低下による tcrt_\text{cr}tcr​ 短縮 第7回
周波数維持 HsysH_\text{sys}Hsys​ と KKK の低下 第8回

予測誤差 必要な予備力 第10〜12回

どれか 1 つでも破れば導入できない。 最も厳しい制約が導入可能量を決める。

Step 1: ベースケースの潮流計算（第4〜6回）

  • 各ノードの電圧・位相角
  • 各線路の潮流・負荷率
  • 系統損失

確認事項: 電圧が 0.95〜1.05 p.u. に入っているか。線路負荷率が 100% 未満か。

Step 2: N-1 事故解析（第2回・第15回）

N-1 基準: 系統内のどの設備 1 つが停止しても、 供給支障や設備の過負荷を起こさないこと。日本の系統計画の基本原則である。

各線路を 1 本ずつ開放して潮流計算を行い、次を確認する。

判定項目 基準
潮流計算が収束するか 収束しない＝系統崩壊のおそれ
電圧 0.90〜1.10 p.u.（事故時は平常時より緩い基準）
線路負荷率 短時間許容（120%）以内
供給支障 発生しないこと

第5回で学んだ高速デカップル法が威力を発揮する場面である （係数行列の LU 分解を 1 回で済ませられる）。

Step 3: 動特性の評価（第7回・第8回）

同期安定度:

  • HsysH_\text{sys}Hsys​ を計算
  • 三相短絡を想定し、δcr\delta_\text{cr}δcr​ と tcrt_\text{cr}tcr​ を等面積法で求める
  • 保護時間（リレー20 ms + 遮断器50 ms = 70 ms）と比較

周波数維持:

  • 系統定数 KKK を計算
  • 最大電源脱落（250 MW）時の RoCoF と定常周波数偏差
  • UFR 整定値（57.0 Hz）に対する余裕

図 15.2　太陽光の導入に伴う系統慣性定数 H と系統定数 K の低下。太陽光 400 MW で H は 4.50 → 2.50 s、K は 150 → 100 MW/Hz に下がる。蓄電池を入れると両方を補える。

図 15.3　120 MW 脱落時の周波数応答。太陽光が増えるほど最低点が深くなり、300 MW では UFR 整定 58.5 Hz を割る。蓄電池による合成慣性と高速応答を加えると回復する。

Step 4: 予測（第10〜12回）

  • 気象データから太陽光出力を推定（第10回）
  • 需要を予測（第11回・第12回）
  • 正味需要（ネットロード）を計算し、ダックカーブを確認
  • 予測誤差から必要な予備力を算出

図 15.4　正味需要（需要 − 太陽光）と火力の最低出力。休日の最小需要 520 MW に対し火力は 320 MW を下回れないため、太陽光 600 MW では正味需要が 6 MW まで下がり、太陽光を絞らざるを得なくなる。

Step 5: 最適化（第14回）

  • 経済負荷配分（ELD）で発電機出力を決定
  • OPF で系統制約を考慮
  • 出力抑制が必要になる時間帯を特定
  • 蓄電池導入の効果を評価

Step 6: 総合評価

各制約から導入可能量を求め、最も厳しいものを採用する。 そして、その制約を緩和する対策を検討する。

図 15.8　対策と制約の対応。力率 0.95 は電圧だけ、蓄電池の合成慣性は周波数と安定度、昼の充電は最低出力、送電線増強は容量と N-1 に効く。律速でない制約に投資しても連系可能量は増えない。

図 15.9　対策による律速の移動。対策なしで 90 MW（律速 周波数）、力率 0.95 を加えても 90 MW のまま、蓄電池（周波数）で 300 MW（律速 最低出力）、昼充電を加えて 430 MW（律速 N-1）と、律速が順に移っていく。

15.3.1 系統モデルの構築とベースケース

"""第15回 総合演習: 沖縄本島系統モデル"""
import numpy as np
import pandas as pd
import pandapower as pp
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Hiragino Sans', 'Yu Gothic', 'DejaVu Sans']

S_BASE, V_BASE, F_N = 1500.0, 132.0, 60.0
H_SYS, PCT_K = 4.5, 1.0                       # [s], [%MW/0.1Hz]

def build_okinawa(pv_mw=0.0, pv_pf=1.0, pv_bus=4):
    """沖縄本島系統の簡略モデル。pv_mw で太陽光容量を指定"""
    net = pp.create_empty_network(f_hz=F_N, sn_mva=100.0)
    names = ["具志川", "牧港", "那覇", "中部", "北部"]
    buses = [pp.create_bus(net, vn_kv=V_BASE, name=n) for n in names]

    pp.create_ext_grid(net, bus=buses[0], vm_pu=1.02, name="具志川")
    pp.create_gen(net, bus=buses[1], p_mw=250.0, vm_pu=1.01, name="牧港",
                  min_p_mw=60.0, max_p_mw=400.0,
                  min_q_mvar=-120.0, max_q_mvar=150.0)

    for b, p, q in [(2, 400.0, 160.0), (3, 350.0, 140.0), (4, 150.0, 60.0)]:
        pp.create_load(net, bus=buses[b], p_mw=p, q_mvar=q, name=names[b])

    for f, t, L in [(0,1,15.0), (1,2,25.0), (2,3,20.0), (3,4,35.0), (0,4,45.0)]:
        pp.create_line_from_parameters(
            net, from_bus=buses[f], to_bus=buses[t], length_km=L,
            r_ohm_per_km=0.06, x_ohm_per_km=0.35, c_nf_per_km=9.0,
            max_i_ka=1.2, name=f"L{f+1}-{t+1}")

    if pv_mw > 0:
        q = 0.0 if pv_pf >= 1.0 else -pv_mw*np.tan(np.arccos(pv_pf))
        pp.create_sgen(net, bus=buses[pv_bus], p_mw=pv_mw, q_mvar=q, name="太陽光")
    return net

net = build_okinawa()
pp.runpp(net)

15.3.2 Step 2: N-1 事故解析

"""第15回: N-1 事故解析"""
def n1_analysis(pv_mw=0.0, pv_pf=1.0, verbose=True):
    """全線路を1本ずつ開放して健全性を確認"""
    rows = []
    for idx in build_okinawa().line.index:
        net = build_okinawa(pv_mw, pv_pf)
        name = net.line.name[idx]
        net.line.at[idx, "in_service"] = False
        try:
            pp.runpp(net)
            rows.append({
                "開放線路": name,
                "収束": "○",
                "V最小": net.res_bus.vm_pu.min(),
                "V最大": net.res_bus.vm_pu.max(),
                "最大負荷率": net.res_line.loading_percent.max(),
                "損失[MW]": net.res_line.pl_mw.sum(),
            })
        except pp.LoadflowNotConverged:
            rows.append({"開放線路": name, "収束": "×",
                         "V最小": np.nan, "V最大": np.nan,
                         "最大負荷率": np.nan, "損失[MW]": np.nan})
    df = pd.DataFrame(rows)
    # 判定（事故時基準: 電圧 0.90〜1.10、負荷率 120% 以内）
    def judge(r):
        if r["収束"] == "×": return "★不収束"
        ng = []
        if r["V最小"] < 0.90: ng.append("低電圧")
        if r["V最大"] > 1.10: ng.append("過電圧")
        if r["最大負荷率"] > 120: ng.append("過負荷")
        return "OK" if not ng else "★" + "/".join(ng)
    df["判定"] = df.apply(judge, axis=1)
    if verbose:
        print("="*66)
        print(f"Step 2: N-1 事故解析（太陽光 {pv_mw:.0f} MW）")
        print("="*66)
        print(df.round(4).to_string(index=False))
        ng = (df.判定 != "OK").sum()
        print(f"\n→ N-1 基準を満たさないケース: {ng} / {len(df)} 件")
    return df

15.3.3 Step 3: 動特性の評価

"""第15回: 同期安定度と周波数維持の評価"""
print("="*66)
print("Step 3: 動特性の評価")
print("="*66)

def dynamics_check(H_sys, pct_k, dP_trip=250.0, S_sys=S_BASE, F_n=F_N):
    K = pct_k/100*S_sys*10                            # [MW/Hz]
    rocof = F_n*(-dP_trip)/(2*H_sys*S_sys)
    dF_ss = -dP_trip/K
    return K, rocof, dF_ss

def transient_stability(H_sys, P_max=2.0, P_m=0.8, F_n=F_N):
    w0 = 2*np.pi*F_n
    d0 = np.arcsin(P_m/P_max)
    cos_cr = P_m/P_max*(np.pi - 2*d0) - np.cos(d0)
    d_cr = np.arccos(np.clip(cos_cr, -1, 1))
    t_cr = np.sqrt(4*H_sys*(d_cr-d0)/(w0*P_m))
    return np.rad2deg(d0), np.rad2deg(d_cr), t_cr

print("\n--- 同期安定度（第7回）---")
d0, dcr, tcr = transient_stability(H_SYS)
print(f"  初期相差角 δ0    = {d0:.2f}°")
print(f"  臨界除去角 δ_cr  = {dcr:.2f}°")
print(f"  臨界除去時間 t_cr = {tcr*1000:.1f} ms")
t_protect = 70.0
print(f"  実際の保護時間   = {t_protect:.0f} ms （リレー20 + 遮断器50）")
print(f"  判定: {'✅ 安定' if tcr*1000 > t_protect else '❌ 脱調'}  "
      f"（余裕 {(tcr*1000-t_protect)/(tcr*1000)*100:.1f}%）")

print("\n--- 周波数維持（第8回）---")
K, rocof, dF = dynamics_check(H_SYS, PCT_K)
print(f"  系統定数 K       = {K:.0f} MW/Hz")
print(f"  RoCoF            = {rocof:+.3f} Hz/s")
print(f"  定常周波数偏差   = {dF:+.3f} Hz  → 到達 {F_N+dF:.3f} Hz")
print(f"  UFR 整定 57.0 Hz に対する余裕: {F_N+dF-57.0:+.3f} Hz")
print(f"  判定: {'✅ UFR 不動作' if F_N+dF > 57.0 else '❌ 負荷遮断'}")

print("\n--- 再エネ導入による慣性・系統定数の低下 ---")
print(f"{'太陽光[MW]':>11} {'H_sys[s]':>10} {'K[MW/Hz]':>10} "
      f"{'RoCoF[Hz/s]':>13} {'到達F[Hz]':>11} {'t_cr[ms]':>10} {'判定':>8}")
for pv in [0, 100, 200, 300, 400, 500, 600]:
    # 太陽光が増えるとその分の同期機を停止 → H と K_G が下がる
    frac = min(pv/900.0, 0.75)                    # 同期機の停止割合
    H_new = H_SYS*(1-frac)
    K_new = K*(1 - 0.75*frac)                     # K_L 分は残る
    _, rc, dfs = dynamics_check(H_new, 1.0)
    K_new = max(K_new, 1e-6)
    dfs = -250.0/K_new
    rc  = F_N*(-250.0)/(2*max(H_new,1e-6)*S_BASE)
    _, _, tc = transient_stability(max(H_new, 0.1))
    ok = (F_N+dfs > 57.0) and (tc*1000 > t_protect)
    print(f"{pv:11d} {H_new:10.2f} {K_new:10.0f} {rc:13.3f} "
          f"{F_N+dfs:11.3f} {tc*1000:10.1f} {'✅' if ok else '❌':>8}")

hours = np.arange(0, 24, 0.5)

# 需要の日変化（沖縄の夏、第11回のモデルを簡略化）

def pv_output(hours, capacity, doy=196, lat=26.21):
    """第10回のモデル（簡略版）"""
    decl = np.deg2rad(23.45)*np.sin(2*np.pi*(284+doy)/365)
    lat_r = np.deg2rad(lat)
    omega = np.deg2rad(15*(hours-12))
    cosz = np.sin(lat_r)*np.sin(decl) + np.cos(lat_r)*np.cos(decl)*np.cos(omega)
    cosz = np.clip(cosz, 0, 1)
    G = 1098*cosz*np.exp(-0.059/np.maximum(cosz, 1e-6))*(cosz > 0)
    T_air = 29.5 - 2.5*np.cos(2*np.pi*(hours-14)/24)
    T_cell = T_air + (45-20)/800*G
    return np.maximum(capacity*(G/1000)*(1-0.004*(T_cell-25))*0.82, 0)

def find_limit(check_fn, lo=0.0, hi=1200.0, tol=1.0):
    """二分探索で制約を満たす最大容量を求める"""
    if not check_fn(lo): return 0.0
    while hi - lo > tol:
        mid = (lo+hi)/2
        if check_fn(mid): lo = mid
        else: hi = mid
    return lo

# --- 制約1: 平常時の電圧 ---
def ok_voltage(pv, pf=1.0):
    try:
        net = build_okinawa(pv, pf); pp.runpp(net)
        return net.res_bus.vm_pu.max() <= 1.05
    except pp.LoadflowNotConverged:
        return False

# --- 制約2: 平常時の線路容量 ---
def ok_thermal(pv, pf=1.0):
    try:
        net = build_okinawa(pv, pf); pp.runpp(net)
        return net.res_line.loading_percent.max() <= 100.0
    except pp.LoadflowNotConverged:
        return False

# --- 制約3: N-1 基準 ---
def ok_n1(pv, pf=1.0):
    df = n1_analysis(pv, pf, verbose=False)
    return (df.判定 == "OK").all()

# --- 制約4: 周波数維持 ---
def ok_frequency(pv):
    frac = min(pv/900.0, 0.95)
    K_new = max(PCT_K/100*S_BASE*10*(1-0.75*frac), 1.0)
    return F_N - 250.0/K_new > 57.0

# --- 制約5: 同期安定度 ---
def ok_stability(pv):
    frac = min(pv/900.0, 0.95)
    H_new = max(H_SYS*(1-frac), 0.05)
    _, _, tc = transient_stability(H_new)
    return tc*1000 > 70.0

# --- 制約6: 火力最低出力（出力抑制なしで運用できるか）---
def ok_min_output(pv):
    return (demand - pv_output(hours, pv)).min() >= P_THERMAL_MIN

15.6 おわりに

本講義で伝えたかったこと

1. 電力系統は物理法則に支配されている

キルヒホッフの法則、エネルギー保存則、熱力学第二法則、回転体の運動方程式。 どんなに高度な AI を使っても、これらを無視することはできない。 第13回・第14回で繰り返し述べたとおり、 AI は物理の代替ではなく、物理計算の高速化と補完である。

2. すべては繋がっている

第3回の P=(VsVr/X)sin⁡δP = (V_sV_r/X)\sin\deltaP=(Vs​Vr​/X)sinδ という 1 つの式が、 潮流計算のヤコビアン（第5回）、等面積法（第7回）、 高速デカップル法（第5回）、直流法潮流（第4回）、 そして電力市場の価格形成（第14回）にまで繋がっていた。

基礎を疎かにしないこと。 それが応用の質を決める。

3. 制約は 1 つではない

第15回の総合演習で見たとおり、 再エネの導入可能量は電圧・容量・N-1・慣性・周波数・最低出力という 複数の制約の中で最も厳しいものが決める。 1 つの制約だけを見て「まだ入る」と判断してはならない。

4. 現場には答えのない問題がある

低慣性系統の運用、再エネの出力抑制の是非、AI の責任の所在。 これらに教科書的な正解はない。 自分で考え、根拠を持って判断することが求められる。 本講義の演習問題に「論じよ」という設問を多く入れたのはそのためである。
