# なぜそう考えるか — 外挿・表形式・リーク

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ木は外挿できないのか</span>
  <span class="bk-body">木の出力は「葉に入った学習データの平均」。学習範囲を超えた入力は端の葉に落ち、端の平均値を返し続ける。記録更新の日は線形の方が素直に伸びる。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ表形式では木が強いのか</span>
  <span class="bk-body">気温 × 時刻 × 曜日のような交互作用と、冷房が入る温度のような閾値を、分割の組合せで自然に表せる。線形回帰は人が項を書かないと表せない。</span>
</div>

<div class="bk alert">
  <span class="bk-title">リークの見つけ方</span>
  <span class="bk-body">「予測時点で本当に手に入るか」を特徴量 1 つずつ問う。精度が良すぎたら疑う。</span>
</div>

</div>

# 持ち帰る 3 点

<div class="ta-main">残差を積む木は強いが、地図の外は歩けない。入力の質が精度の上限を決める</div>

<div class="ta-points">
