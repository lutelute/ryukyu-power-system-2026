📌 一言でいうと：系統の配線は 1 つの行列 Y_bus に、各母線の需給は電力方程式に集約される。解くべき未知数は N_PV + 2N_PQ 個。

🪄 たとえ話：道路網の「通りやすさ表」

崩れる点：道は「通れる／通れない」だが、電気は位相も持つ。だから式が非線形になる。

📰 事例：数千母線の実系統と疎行列 IEEE 118 母線でも Y_bus の非零要素は 3.4%、1 万母線なら推定 0.06% しかない。各母線につながる線路は数本だから。密行列で持つと 1 万母線で 1 億要素・約 1.6 GB。疎行列を使わないと、中央給電の EMS は数分ごとの潮流計算を回せない。

📰 事例：電力市場を動かす直流法潮流 地点別限界価格（第14回）や連系線の空き容量の評価は、線形で 1 回で解ける直流法潮流で回っている。IEEE 14 母線で交流法と比べると線路潮流のずれは最大 9 MW。「厳密でなくても速くて十分」な場面が実務には多い。

🤔 この回の式で読むと：今日の 2 つの道具（Y_bus と直流法）がそのまま現場にある、という話。3.4% と 9 MW は後の図で実際に出す。

🤔 なぜ非線形なのか 与えられるのが電流ではなく電力だから。S = VI* に I = Y_bus V を入れると V の積と cos/sin が入り、連立一次方程式にならない。電流で指定できるなら潮流計算は要らない。

🤔 なぜ母線は 3 種類なのか 各母線は P, Q, V, θ の 4 量のうち 2 つを与える。負荷は P, Q（PQ）、AVR 付き発電機は P と V（PV）。損失は解くまで分からないので、誰かが帳尻を引き受ける（スラック：V, θ）。

⚠ 落とし穴 スラック母線は 1 つだけ。2 つ置くと損失の分担が決まらず解が定まらない。位相の基準もスラックが担う。発電機があっても電圧を制御しなければ PV ではない。

この回の地図：Ⅰ Y_bus の組み立て — 機械的に作れる → Ⅱ 電力方程式の導出 — キルヒホッフから P, Q へ → Ⅲ 母線種別と未知数の数 — なぜ 3 種類か → Ⅳ 直流法潮流 — 手計算で概略をつかむ

そもそも潮流計算とは何か

潮流計算（power flow / load flow）とは、 「どの母線にどれだけ発電機と負荷があるか」を与えたとき、 各母線の電圧（大きさと位相）と、各線路を流れる電力を求める計算である。

電力系統解析で最も基本かつ最も頻繁に使われる計算で、次のような場面で必須になる。

  • 設備計画: 新しい送電線・発電所を作るべきか
  • 運用計画: 明日この運転パターンで過負荷や電圧逸脱が起きないか
  • 系統事故解析: ある線路が切れたとき残りの線路は耐えられるか（N-1 基準、第15回）
  • 最適化・市場運用: 発電機出力の最適配分（OPF、第14回）

なぜスラック母線が必要か — 2 つの理由がある。

  1. 損失が事前に分からないから。 全母線で PiP_iPi​ を指定してしまうと、∑Pigen=∑Piload\sum P_i^\text{gen} = \sum P_i^\text{load}∑Pigen​=∑Piload​ を 満たすように与えなければならない。しかし線路損失は解いてみないと分からず、 事前に決められない。そこで1 つの母線だけ PPP を自由にし、 収支の帳尻（＝損失分）を吸収させる。これがスラック（slack = たるみ）の意味である。

  2. 位相角の基準が必要だから。 電力方程式には θij=θi−θj\theta_{ij} = \theta_i - \theta_jθij​=θi​−θj​ という差しか現れない。 したがって全ての θi\theta_iθi​ に同じ定数を足しても方程式は変わらない （解が一意に定まらない）。そこで1 つの母線の位相を θ1=0\theta_1 = 0θ1​=0 に固定する。

本講義の約束: 記号表のとおり、スラックノードは必ずノード番号 1 に取る。

スラックノードと基準ノードは本来別物（教科書 4.2 節）: 損失を吸収する役目がスラックノード、位相の基準を与える役目が基準ノードである。 別々に選ぶこともできるが、通常は同じノードを選ぶ。本講義でも同一とする。

浮遊ノード（floating node）: 送電線の中間点や変電所には、 ブランチを結びつけているだけで電力の発生も消費もしないノードがある。 これを浮遊ノードと呼び、Pi=Qi=0P_i = Q_i = 0Pi​=Qi​=0 の PQ 指定ノードとして扱う。

実系統のモデル化では浮遊ノードが多数現れる。P=Q=0P=Q=0P=Q=0 を指定するだけでよく、 特別な扱いは要らないが、未知数の数には算入されることに注意すること。

PV 母線で VVV が既知なのはなぜか: 発電機には AVR（自動電圧調整器）があり、 励磁電流を調整して端子電圧を一定に保つ。ただし無効電力の出力には限界 Qimin≤Qi≤QimaxQ_i^\text{min} \leq Q_i \leq Q_i^\text{max}Qimin​≤Qi​≤Qimax​ があり、これを超えると電圧を保てなくなる。 その場合、QiQ_iQi​ を限界値に固定してPQ 母線に切り替える（第5回で扱う）。

"""第4回 デモ1: Y_bus の構築（4.2.2 の 3母線系統）"""
import numpy as np

def build_ybus(n_bus, lines, shunts=None):
    """
    lines : list of (from, to, R, X, B_half)   母線番号は 1 始まり
    shunts: dict {bus: y_shunt}                母線直結の調相設備
    """
    Y = np.zeros((n_bus, n_bus), dtype=complex)
    for f, t, R, X, B_half in lines:
        i, j = f - 1, t - 1
        y = 1.0 / complex(R, X)
        # 非対角: 符号反転
        Y[i, j] -= y
        Y[j, i] -= y
        # 対角: 直列分 + 充電分
        Y[i, i] += y + 1j * B_half
        Y[j, j] += y + 1j * B_half
    if shunts:
        for bus, ys in shunts.items():
            Y[bus - 1, bus - 1] += ys
    return Y

4.3.3 電力方程式の評価（注入電力の計算）

"""第4回 デモ3: 電圧を与えて注入電力を計算する（順問題）"""
import numpy as np

def power_injection(V, theta, Y):
    """電力方程式で P, Q を計算（4.2.3 の式そのまま）"""
    n = len(V)
    G, B = Y.real, Y.imag
    P = np.zeros(n)
    Q = np.zeros(n)
    for i in range(n):
        for j in range(n):
            th = theta[i] - theta[j]
            P[i] += V[i]*V[j]*(G[i, j]*np.cos(th) + B[i, j]*np.sin(th))
            Q[i] += V[i]*V[j]*(G[i, j]*np.sin(th) - B[i, j]*np.cos(th))
    return P, Q

4.6 まとめ

キーポイント

  • Ybus\mathbf{Y}_\text{bus}Ybus​ の作り方（機械的に組める）: Yii=∑j≠i(yij+yijsh2)+yishunt,Yij=−yijY_{ii} = \sum_{j\neq i}\left(y_{ij}+\frac{y_{ij}^\text{sh}}{2}\right) + y_i^\text{shunt}, \qquad Y_{ij} = -y_{ij}Yii​=j=i∑​(yij​+2yijsh​​)+yishunt​,Yij​=−yij​ 検算: 充電容量を除けば各行の和は 0。

  • 電力方程式: Pi=Vi∑jVj(Gijcos⁡θij+Bijsin⁡θij),Qi=Vi∑jVj(Gijsin⁡θij−Bijcos⁡θij)P_i = V_i\sum_j V_j(G_{ij}\cos\theta_{ij}+B_{ij}\sin\theta_{ij}), \quad Q_i = V_i\sum_j V_j(G_{ij}\sin\theta_{ij}-B_{ij}\cos\theta_{ij})Pi​=Vi​j∑​Vj​(Gij​cosθij​+Bij​sinθij​),Qi​=Vi​j∑​Vj​(Gij​sinθij​−Bij​cosθij​)
  • 非線形の理由は ViVjV_iV_jVi​Vj​ の積と cos⁡θij,sin⁡θij\cos\theta_{ij}, \sin\theta_{ij}cosθij​,sinθij​。 電流を未知数にすれば線形だが、実際に与えられるのは電力なので避けられない。
  • 母線種別は3つ。各母線で (P,Q,V,θ)(P,Q,V,\theta)(P,Q,V,θ) の 4 量のうち 2 つを与える。
    • スラック（V,θV,\thetaV,θ 既知）: 損失の吸収と位相の基準という 2 つの役割。必ず 1 個。
