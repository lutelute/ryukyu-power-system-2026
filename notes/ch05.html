まず直感で（3 分でつかむ）

📌 一言でいうと：潮流方程式は非線形だが、今いる点で接線を引いて交点へ跳ぶことを繰り返せば、3〜5 回で解に着く。跳ぶ方向を決めるのがヤコビアン。

🪄 たとえ話：霧の坂道を谷底へ下りる

霧の坂道 ニュートン・ラフソン法
見えるのは 足元の傾き だけ 傾き＝ヤコビアン（1 階微分）
傾きの方向へ、傾きが急なら大きく進む 修正量 Δx = −J⁻¹ f(x)
谷底に近づくほど歩幅は自然に小さくなる 誤差が 2 乗で縮む（2 次収束）
手探りで一歩ずつ下りるやり方もある 手探り＝ガウス・ザイデル法（遅い）
出発点が悪いと隣の谷へ行く 出発点＝フラットスタート（V=1、θ=0）

崩れる点：坂道は 1 次元だが潮流は数千次元。それでも「接線で跳ぶ」考え方は全く同じ。Ⅳ章の初期値の図で「隣の谷」を実際に見せる。

📰 事例：収束しない潮流計算 運用の現場では、潮流計算が収束しないことを 電圧安定限界の兆候 として扱う。解が「見つからない」のではなく「存在しない」状態に近づいている。2003 年北米大停電の調査でも、状態推定が収束せず運用者が系統の状態を把握できない時間帯があった。

📰 事例：EMS は毎分、何百回も解く 中央給電の計算機は数分ごとに潮流を回し、想定事故（N-1）を数百ケース評価する。高速デカップル法や直流法が使われるのは、この回数をこなすため。「速さ」は実務では品質の一部。

🤔 この回の式で読むと：今日は「どう解くか」だけでなく「なぜ解けないことがあるか」まで押さえる。Ⅳ章の Q 限界の図で、負荷 2.5 倍から先は本当に解が無くなるのを見せる。

🤔 なぜ 2 次収束なのか 接線近似で捨てたのは 2 次以降の項だから、次の誤差は今の誤差の 2 乗に比例する。0.90 → 0.048 → 4e-4 → 3e-8 と桁が倍々で増え、母線数は式に出てこない。

🤔 なぜ N と M を落とせるのか 送電線は X ≫ R なので ∂P/∂V と ∂Q/∂θ が小さい（X/R = 10 で ‖N‖/‖H‖ ≈ 0、‖M‖/‖L‖ 0.25）。落としても跳ぶ方向は大きく狂わず、反復を増やせば同じ解に着く。

⚠ PV 母線の Q 限界 発電機は無限に Q を出せない。限界を超えたら Q を上限に固定して PQ 母線に切り替え、電圧は下がる。切替が多発する系統は電圧が苦しく、その先で解が無くなる。

この回の地図：Ⅰ 接線で跳ぶ — 1 変数のニュートン法と 2 次収束 → Ⅱ 潮流方程式へ — ヤコビアン H, N, M, L と 3 母線の実例 → Ⅲ 高速デカップル法 — P–δ / Q–V 分離で軽くする → Ⅳ 初期値と PV 母線の Q 限界 — 「解けない」を読む

5.1 導入

学習目標

  1. ガウス・ザイデル法の反復式を導出し、その収束の遅さの理由を説明できる。
  2. ニュートン・ラフソン法を潮流計算に適用し、ヤコビアン行列を導出できる。
  3. ヤコビアン行列の 4 分割構造 H,N,M,L\mathbf{H},\mathbf{N},\mathbf{M},\mathbf{L}H,N,M,L を書き下せる。
  4. 高速デカップル法の近似が何に基づくかを、第3回の P-δ/Q-V 分離から説明できる。
  5. PV 母線の QQQ 限界違反時の母線種別切替を実装レベルで説明できる。

5.2.5 初期値の与え方 — フラットスタート

ニュートン法は初期値に敏感である。潮流計算では次を標準とする。

Vi(0)=1.0 p.u. (PQ 母線),θi(0)=0 rad (全母線)V_i^{(0)} = 1.0\ \text{p.u.}\ (\text{PQ 母線}), \qquad \theta_i^{(0)} = 0\ \text{rad}\ (\text{全母線})Vi(0)​=1.0 p.u. (PQ 母線),θi(0)​=0 rad (全母線)

PV 母線・スラック母線は指定値を用いる。これをフラットスタートという。

なぜうまくいくのか: 正常運転時の系統では電圧が 0.95〜1.05 p.u.、 位相差が数度〜数十度に収まる。フラットスタートは真の解のすぐ近くにある。 単位法の利点（第3回）がここでも効いている。

うまくいかない場合: 重負荷時、電圧安定限界に近い系統、 太陽光大量導入で逆潮流が大きい系統では発散することがある。対策は

  • 負荷を段階的に増やしながら解く（継続法 / continuation power flow）
  • ガウス・ザイデル法で 1〜2 反復して初期値を改善する
  • ステップ幅を制限する（Δθ\Delta\thetaΔθ を最大 10° に制限するなど）

5.2.6 高速デカップル法（FDLF）

第3回の重要な結論を思い出す: 架空送電線では X≫RX \gg RX≫R であり、

P≈ViVjXθij(位相に強く依存),Q≈Vj(Vi−Vj)X(電圧の大きさに強く依存)P \approx \frac{V_iV_j}{X}\theta_{ij} \quad(\text{位相に強く依存}), \qquad Q \approx \frac{V_j(V_i-V_j)}{X} \quad(\text{電圧の大きさに強く依存})P≈XVi​Vj​​θij​(位相に強く依存),Q≈XVj​(Vi​−Vj​)​(電圧の大きさに強く依存)

したがってヤコビアンの非対角ブロック N,M\mathbf{N}, \mathbf{M}N,M は H,L\mathbf{H}, \mathbf{L}H,L に比べて小さい。

J=[HNML]≈[H00L]\mathbf{J} = \begin{bmatrix}\mathbf{H} & \mathbf{N}\\ \mathbf{M} & \mathbf{L}\end{bmatrix} \approx \begin{bmatrix}\mathbf{H} & \mathbf{0}\\ \mathbf{0} & \mathbf{L}\end{bmatrix}J=[HM​NL​]≈[H0​0L​]

これで 2 つの独立した方程式に分離できる（デカップリング）。

ΔP=HΔθ,ΔQ=L ΔV/V\Delta\mathbf{P} = \mathbf{H}\Delta\boldsymbol{\theta}, \qquad \Delta\mathbf{Q} = \mathbf{L}\,\Delta\mathbf{V}/\mathbf{V}ΔP=HΔθ,ΔQ=LΔV/V

Stott の高速デカップル法では、さらに次の近似を加える。

  • cos⁡θij≈1\cos\theta_{ij} \approx 1cosθij​≈1（位相差が小さい）
  • Gijsin⁡θij≪BijG_{ij}\sin\theta_{ij} \ll B_{ij}Gij​sinθij​≪Bij​（X≫RX \gg RX≫R）
  • Qi≪BiiVi2Q_i \ll B_{ii}V_i^2Qi​≪Bii​Vi2​

すると H,L\mathbf{H}, \mathbf{L}H,L が電圧・位相に依存しない定数行列 B′,B′′\mathbf{B}', \mathbf{B}''B′,B′′ になる。

ΔPV=B′ Δθ,ΔQV=B′′ ΔV\frac{\Delta\mathbf{P}}{\mathbf{V}} = \mathbf{B}'\,\Delta\boldsymbol{\theta}, \qquad \frac{\Delta\mathbf{Q}}{\mathbf{V}} = \mathbf{B}''\,\Delta\mathbf{V}VΔP​=B′Δθ,VΔQ​=B′′ΔV

ここが重要: B′,B′′\mathbf{B}', \mathbf{B}''B′,B′′ は定数なので、 LU 分解を最初に 1 回だけ行えばよい。以後の反復は前進・後退代入だけで済む。 反復回数は増える（10〜20 回）が、1 反復が圧倒的に軽いので総計算時間は短縮される。

適用限界: 配電系統では R/XR/XR/X が 1 を超えることがあり（X≫RX \gg RX≫R が成り立たない）、 高速デカップル法は収束しない。配電系統には後退前進法など別の手法を使う。

5.2.7 PV 母線の QQQ 限界処理

発電機の無効電力出力には限界がある。反復の各段階で次を確認する。

各反復の終わりに、全 PV 母線について:
    Q_i を電力方程式から計算
    if Q_i > Q_i^max:
        Q_i ← Q_i^max とし、母線 i を PQ 母線に変更   # 電圧は下がる
    elif Q_i < Q_i^min:
        Q_i ← Q_i^min とし、母線 i を PQ 母線に変更   # 電圧は上がる
    else:
        PV 母線のまま

逆の切り戻しも必要: PQ に切り替えた母線の電圧が指定値を超えた（QmaxQ^\text{max}Qmax 側の場合）なら、 PV 母線に戻す。これを怠ると解が不正確になる。

物理的意味: QmaxQ^\text{max}Qmax に達するとは、発電機が励磁の限界まで無効電力を出しており、 それ以上電圧を支えられない状態である。この母線の電圧は指定値より下がる。 電圧崩壊の前兆であり、実務上きわめて重要な情報である（第7回・第14回）。

図 5.8　PV 母線の Q 限界（3 母線系統、母線 2 の Q_max = 0.30 p.u.）。左：母線 2 を電圧指定値に保つのに要る無効電力 Q₂。電圧を上げるほど、負荷が重いほど Q₂ が要る。右：母線 3 の負荷を増やすと 1.9 倍で Q₂ が上限に達し、PQ 母線に切り替えると V₂ は 1.02 を保てず 2.4 倍で 0.982 まで下がる。2.5 倍を超えると解が無くなり NR 法は収束しない。

5.3.1 ガウス・ザイデル法の実装

"""第5回 デモ1: ガウス・ザイデル法による潮流計算"""
import numpy as np

def gauss_seidel(Ybus, bus_type, P_sch, Q_sch, V_mag,
                 tol=1e-6, max_iter=500, accel=1.6):
    """
    bus_type: 0=slack, 1=PV, 2=PQ
    戻り値: V(複素), 反復回数, 収束履歴
    """
    n = len(bus_type)
    V = np.where(bus_type == 0, V_mag, 1.0).astype(complex)
    V[bus_type == 1] = V_mag[bus_type == 1]
    Q = Q_sch.copy()
    history = []

    for it in range(max_iter):
        V_prev = V.copy()
        for i in range(n):
            if bus_type[i] == 0:
                continue
            if bus_type[i] == 1:                      # PV: Q を推定
                Q[i] = -np.imag(np.conj(V[i]) * (Ybus[i, :] @ V))
            # ガウス・ザイデル更新式
            sum_YV = Ybus[i, :] @ V - Ybus[i, i]*V[i]
            V_new  = ((P_sch[i] - 1j*Q[i]) / np.conj(V[i]) - sum_YV) / Ybus[i, i]
            V_new  = V[i] + accel*(V_new - V[i])      # 加速
            if bus_type[i] == 1:                      # PV: 大きさを戻す
                V_new = V_mag[i] * V_new/abs(V_new)
            V[i] = V_new
        err = np.abs(V - V_prev).max()
        history.append(err)
        if err < tol:
            return V, it+1, history
    return V, max_iter, history


# --- 3母線テストケース ---
from_to = [(1,2,0.02,0.06,0.03), (1,3,0.08,0.24,0.025), (2,3,0.06,0.18,0.02)]
n = 3
Y = np.zeros((n,n), dtype=complex)
for f,t,R,X,B in from_to:
    i,j = f-1,t-1; y = 1/complex(R,X)
    Y[i,j] -= y; Y[j,i] -= y
    Y[i,i] += y + 1j*B; Y[j,j] += y + 1j*B

bus_type = np.array([0, 1, 2])                 # slack, PV, PQ
P_sch    = np.array([0.0,  0.50, -1.00])       # p.u.
Q_sch    = np.array([0.0,  0.00, -0.40])
V_mag    = np.array([1.05, 1.02, 1.00])

V, iters, hist = gauss_seidel(Y, bus_type, P_sch, Q_sch, V_mag)

5.3.2 ニュートン・ラフソン法の実装

"""第5回 デモ2: ニュートン・ラフソン法による潮流計算（完全版）"""
import numpy as np

def newton_raphson(Ybus, bus_type, P_sch, Q_sch, V_mag,
                   tol=1e-8, max_iter=20, verbose=True):
    n = len(bus_type)
    G, B = Ybus.real, Ybus.imag
    pv = np.where(bus_type == 1)[0]
    pq = np.where(bus_type == 2)[0]
    pvpq = np.concatenate([pv, pq])

    V     = V_mag.copy().astype(float)
    theta = np.zeros(n)                       # フラットスタート
    history = []

    def calc_PQ(V, theta):
        Vc = V*np.exp(1j*theta)
        S  = Vc*np.conj(Ybus @ Vc)
        return S.real, S.imag

    for it in range(max_iter):
        P, Q = calc_PQ(V, theta)
        dP = P_sch[pvpq] - P[pvpq]
        dQ = Q_sch[pq]   - Q[pq]
        mismatch = np.concatenate([dP, dQ])
        err = np.abs(mismatch).max()
        history.append(err)
        if verbose:
            print(f"  反復 {it}: 最大ミスマッチ = {err:.3e}")
        if err < tol:
            return V, theta, it, history

        # --- ヤコビアン構築 ---
        H = np.zeros((len(pvpq), len(pvpq)))
        N = np.zeros((len(pvpq), len(pq)))
        M = np.zeros((len(pq),   len(pvpq)))
        L = np.zeros((len(pq),   len(pq)))

        for a, i in enumerate(pvpq):
            for b, j in enumerate(pvpq):
                if i == j:
                    H[a,b] = -Q[i] - B[i,i]*V[i]**2
                else:
                    th = theta[i]-theta[j]
                    H[a,b] = V[i]*V[j]*(G[i,j]*np.sin(th) - B[i,j]*np.cos(th))
            for b, j in enumerate(pq):
                if i == j:
                    N[a,b] = P[i] + G[i,i]*V[i]**2
                else:
                    th = theta[i]-theta[j]
                    N[a,b] = V[i]*V[j]*(G[i,j]*np.cos(th) + B[i,j]*np.sin(th))
        for a, i in enumerate(pq):
            for b, j in enumerate(pvpq):
                if i == j:
                    M[a,b] = P[i] - G[i,i]*V[i]**2
                else:
                    th = theta[i]-theta[j]
                    M[a,b] = -V[i]*V[j]*(G[i,j]*np.cos(th) + B[i,j]*np.sin(th))
            for b, j in enumerate(pq):
                if i == j:
                    L[a,b] = Q[i] - B[i,i]*V[i]**2
                else:
                    th = theta[i]-theta[j]
                    L[a,b] = V[i]*V[j]*(G[i,j]*np.sin(th) - B[i,j]*np.cos(th))

        J = np.block([[H, N], [M, L]])
        dx = np.linalg.solve(J, mismatch)

        theta[pvpq] += dx[:len(pvpq)]
        V[pq]       *= (1 + dx[len(pvpq):])        # ΔV/V 形式なので比率で更新

    return V, theta, max_iter, history


print("ニュートン・ラフソン法:")
V_nr, th_nr, it_nr, hist_nr = newton_raphson(Y, bus_type, P_sch, Q_sch, V_mag)

    print(f"{i+1:4d} {V_nr[i]:11.5f} {np.rad2deg(th_nr[i]):9.3f}")

例題 5-3（QQQ 限界処理）

PV 母線として設定した発電機母線（指定電圧 1.03 p.u.、Qmax=0.50Q^\text{max} = 0.50Qmax=0.50 p.u.）で、 反復の途中で Q=0.68Q = 0.68Q=0.68 p.u. と計算された。

  2. 処理後、この母線の電圧はどうなると予想されるか。

(1) Q=0.68>Qmax=0.50Q = 0.68 > Q^\text{max} = 0.50Q=0.68>Qmax=0.50 なので限界違反。 QQQ を 0.50 p.u. に固定し、この母線をPQ 母線に変更する。 以後この母線の VVV は未知数となり、QQQ の式が方程式に加わる。

(3) この発電機は励磁の限界に達しており、これ以上電圧を支えられない。 系統の無効電力が不足している状態であり、電圧不安定・電圧崩壊の前兆である。 運用上の対策としては

  • 調相設備（電力用コンデンサ）の投入
  • 他の発電機の電圧設定値を上げる
  • 重負荷の場合は負荷制限

が考えられる。潮流計算の結果として PV → PQ 切替が多発する系統は、 無効電力の余裕が乏しいと判断できる。

5.6 まとめ

キーポイント

  • ガウス・ザイデル法: 実装は簡単だが1次収束で遅く、母線数に比例して反復回数が増える。 現代ではニュートン法の初期値生成用途に限られる。
  • ニュートン・ラフソン法: 2次収束で、系統規模によらず 3〜5 回で収束する。 実務標準。修正方程式は [ΔPΔQ]=[HNML][ΔθΔV/V]\begin{bmatrix}\Delta\mathbf{P}\\ \Delta\mathbf{Q}\end{bmatrix} = \begin{bmatrix}\mathbf{H}&\mathbf{N}\\ \mathbf{M}&\mathbf{L}\end{bmatrix} \begin{bmatrix}\Delta\boldsymbol\theta\\ \Delta\mathbf{V}/\mathbf{V}\end{bmatrix}[ΔPΔQ​]=[HM​NL​][ΔθΔV/V​]
  • ヤコビアンの対角要素は Pi,QiP_i, Q_iPi​,Qi​ で書けるので、ミスマッチ計算の結果を再利用する。
  • フラットスタート（V=1.0V=1.0V=1.0、θ=0\theta=0θ=0）が有効なのは、 単位法により正常解が 1.0 近傍に来るため。
  • 高速デカップル法は、第3回の P-δ / Q-V 分離（X≫RX\gg RX≫R）に基づき N≈M≈0\mathbf{N}\approx\mathbf{M}\approx\mathbf{0}N≈M≈0 と近似する。 係数行列が定数になり LU 分解が 1 回で済むので、 N-1 事故解析のような大量ケース計算で威力を発揮する。 ただし R/XR/XR/X の大きい配電系統には使えない。
  • PV 母線の QQQ 限界違反 → PQ 母線への切替。切替の多発は 無効電力余裕の不足＝電圧崩壊の前兆を意味する重要な情報である。
