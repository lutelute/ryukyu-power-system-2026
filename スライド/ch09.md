# PWM — 変調波と搬送波を比べるだけ

## 読み方｜上が比較、下が出力。矩形波の平均が正弦波になる

![w:620](../図/ch09_pwm.png)

<div class="fs-points">
- 変調波（60 Hz）が搬送波より上なら ON
- 出力は ±Vdc/2 の矩形しかない
- その平均が **m·Vdc/2 = 270 V** の正弦波
- 幅で電圧の大小を表している
</div>

<div class="fs-conclusion">インバータは正弦波を「増幅」しているのではない。矩形の幅を変えて、平均として正弦波を作っている。</div>

<!-- note: 実機のスイッチング周波数は数 kHz〜数十 kHz。この図は見やすさのため 1,260 Hz にしている。 -->

# 導出 — 基本波の大きさはどう決まるか

<div class="sec">
  <span class="sec-title">① 1 スイッチング周期の平均｜幅が変調波に比例する</span>
  <span class="sec-body">搬送波が三角波なら、ON になる時間の割合は変調波の値に線形に比例する。だから 1 周期の平均電圧は変調波の形をそのままなぞる。</span>
</div>

<div class="sec">
  <span class="sec-title">② 相電圧の基本波｜V̂₁ = m·Vdc/2</span>
  <span class="sec-body">出力の振れ幅が ±Vdc/2 で、変調率 m がその何割まで使うかを決める。m ≤ 1 が **線形領域**。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 線間の実効値｜√3 倍して √2 で割る</span>
  <span class="sec-body">V_LL = (√3/√2)·m·Vdc/2 ≈ **0.612 m Vdc**。600 V・m = 0.9 なら 328 V で、400 V 系統には少し足りない。</span>
</div>

<!-- note: ③の数字で「なぜ太陽光の PCS は昇圧トランスを持つか」を説明できる。 -->

---

<!-- _class: figure-story -->
<!-- source: コード/fig_ch09.py -->

# 変調率と出力電圧 — m ≤ 1 では比例

## 読み方｜実測（DFT で取り出した基本波）と理論式が線形領域で一致する

![w:600](../図/ch09_modulation.png)

<div class="fs-points">
- m = 0.9 → 相電圧の振幅 **268 V**
- 線間実効値 **328 V**
- m > 1 は過変調（低次高調波が出る）
- 理論 m·Vdc/2 と実測がぴったり重なる
</div>

<div class="fs-conclusion">直流電圧が足りなければ、m を上げても限界がある。だから系統電圧に対して十分な Vdc を確保する。</div>

<!-- note: 過変調は非常時に電圧を絞り出す手段。常用すると 5 次・7 次の高調波が増える。 -->

# LCL フィルタ — 高い周波数を急峻に落とす

## 読み方｜両対数。L 単体より傾きが急で、同じ減衰を小さな部品で得られる

![w:600](../図/ch09_lcl.png)

# 合成慣性 — 第8回の周波数問題への答え

<div class="eq-main">

$$\Delta P_\text{inv} = -\frac{2 H_v S}{f_0}\,\frac{df}{dt}$$

</div>

<div class="eq-desc">
  <span class="sym">$H_v$</span>
  <span>仮想慣性定数 [s]。制御で「重さ」を模擬する。エネルギー源は直流側の蓄電</span>
  <span class="sym">$df/dt$</span>
  <span>周波数変化率。測るのに数十〜数百 ms かかる。ここが真の慣性との決定的な差</span>
  <span class="sym">$df/dt < 0$</span>
  <span>符号：周波数が下がる（df/dt < 0）ときに出力を増やす。第7回の動揺方程式と同じ形</span>
  <span class="sym">$\Delta t$</span>
  <span>限界：数秒しか続かない。定常偏差を消すのは K（ガバナ・LFC）の仕事</span>
</div>

<!-- note: 真の慣性は「測らずに物理的に出る」。合成慣性は「測ってから出す」。この差が遅れになる。 -->

# 遅れがあると効果が薄れる

## 読み方｜同じ H_v = 3.0 s でも、df/dt の測定に時間がかかると効かない

![w:620](../図/ch09_delay.png)

# 例題 1 — 600 V の直流から何ボルト出せるか

<div class="st-container">

<div class="st-step">
  <span class="st-num">1</span>
  <span class="st-title">条件</span>

# なぜそう考えるか — dq・単独運転・合成慣性

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ dq 変換をするのか</span>
  <span class="bk-body">正弦波のままでは PI 制御に定常偏差が残る。位相に同期した座標に乗ると正弦波が直流に見え、普通の PI で偏差ゼロにできる。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ単独運転検出が必須なのか</span>
  <span class="bk-body">系統が切れた後も送電を続けると、作業員の感電、電圧・周波数の逸脱による機器破損、再閉路時の位相不一致が起きる。だから「系統が無い」ことを検出して止める。</span>
</div>

<div class="bk alert">
  <span class="bk-title">合成慣性は真の慣性ではない</span>
  <span class="bk-body">df/dt を測ってから出すので遅れる。蓄電が無ければ続かない。RoCoF の初期値は変えられない。</span>
</div>

</div>

# 持ち帰る 3 点

<div class="ta-main">インバータは制御そのものが電源の性格を決める。フォロイングは従い、フォーミングは作る</div>

<div class="ta-points">
<li>PWM：V̂₁ = m·Vdc/2、高調波は m_f 付近。dq 変換で PI が効く</li>

<li>合成慣性は真の慣性ではない。遅れとエネルギー源が要る</li>
</div>
