まず直感で（3 分でつかむ）

📌 一言でいうと：インバータはスイッチで正弦波を作る電源。回転体がないので慣性はゼロだが、制御の設計次第で電圧と周波数を支える側に回れる。

🪄 たとえ話：合唱の「合わせ手」と「指揮者」

合唱 インバータ
合わせ手は周りの声を聞いて 合わせて歌う グリッドフォロイング：PLL で追従
誰も歌っていないと 合わせられない 系統が無いと動けない → 単独運転検出

崩れる点：合唱は「合わせる」だけだが、インバータは電流の大きさと位相を数万分の 1 秒ごとに決めている。その速さが強みでもある。

📰 事例：2016年9月 南オーストラリア州 全域停電 暴風で送電塔が倒れ、電圧低下が短時間に何度も起きた。風力発電の保護設定（電圧低下に耐える回数の上限）で出力が 急減 し、州外との連系線が過負荷で遮断。州全体がブラックアウトした。

📰 事例：2017年 同じ州に置かれた大型蓄電池 約 100 MW の蓄電池が周波数調整の市場に参加し、周波数の落ち込みに 0.1 秒台で応答した。慣性を持たない電源でも、制御が速ければ周波数を支えられることを実系統で示した。

🤔 この回の式で読むと：同じインバータ電源が、設定次第で事故の引き金にも救い手にもなる。今日はその設計を学ぶ。

🤔 なぜ dq 変換をするのか 正弦波のままでは PI 制御に定常偏差が残る。位相に同期した座標に乗ると正弦波が直流に見え、普通の PI で偏差ゼロにできる。

🤔 なぜ単独運転検出が必須なのか 系統が切れた後も送電を続けると、作業員の感電、電圧・周波数の逸脱による機器破損、再閉路時の位相不一致が起きる。だから「系統が無い」ことを検出して止める。

⚠ 合成慣性は真の慣性ではない df/dt を測ってから出すので遅れる。蓄電が無ければ続かない。RoCoF の初期値は変えられない。

この回の地図：Ⅰ PWM — スイッチのオン・オフで正弦波を作る → Ⅱ dq 変換と制御 — 交流を直流にして PI で扱う → Ⅲ フォロイングとフォーミング、単独運転検出 → Ⅳ 第6回・第8回への答え — Volt-Var 制御と合成慣性

9.2 理論

9.2.1 インバータとは

インバータは直流を交流に変換する装置である（逆変換装置）。

変換 名称 用途
交流 → 直流 順変換装置（コンバータ・整流器） 電源装置、HVDC 送電端
直流 → 交流 インバータ（逆変換装置） 太陽光・蓄電池の連系、モータ駆動
交流 → 交流 周波数変換装置 周波数変換所（第2回）

電力系統でインバータが必要になる場面:

  • 太陽光発電 — 出力が直流。必ずインバータ（パワーコンディショナ、PCS）が要る
  • 蓄電池 — 同上
  • 風力発電（可変速機） — 発電周波数が風速で変わるため、一度直流にして系統周波数に合わせる
  • HVDC 送電（第2回） — 受電端で直流を交流に戻す
  • FACTS 機器（第7回） — STATCOM は自励式インバータそのもの

9.2.2 PWM 制御の原理

インバータのスイッチ（IGBT など）はオンかオフしかない。 これで正弦波を作るのが PWM（Pulse Width Modulation、パルス幅変調）である。

＼            比較

9.2.4 三相インバータの制御 — dq 変換と PLL

三相の交流量（a,b,ca,b,ca,b,c 相）は時間とともに正弦波状に変化するため、 そのままでは PI 制御などの一般的な制御手法が使いにくい。

そこで回転座標変換（dq 変換）を用いる。

  abc（三相交流）  ──[Clarke]──→  αβ（静止2軸）  ──[Park]──→  dq（回転2軸）
     正弦波                          正弦波                    直流量！

dq 変換の威力: 系統周波数と同期して回転する座標系から見ると、 平衡三相の正弦波は直流量に見える。直流量なら PI 制御で定常偏差なく制御できる。

さらに ddd 軸を系統電圧ベクトルに合わせると（vq=0v_q = 0vq​=0 とすると）、

P=32vdid,Q=−32vdiq\boxed{P = \frac{3}{2}v_d i_d, \qquad Q = -\frac{3}{2}v_d i_q}P=23​vd​id​,Q=−23​vd​iq​​

idi_did​ で有効電力、iqi_qiq​ で無効電力を独立に制御できる。 これが系統連系インバータ制御の中核である。

PLL（Phase Locked Loop、位相同期回路）: dq 変換には系統電圧の位相が必要である。これを検出するのが PLL である。

  系統電圧 ──→[dq変換]──→ v_q ──→[PI]──→ Δω ──→(＋ω₀)──→[∫]──→ θ
                  ↑                                              │
                  └──────────────────────────────────────────────┘

vq=0v_q = 0vq​=0 となるように角周波数を調整すると、θ\thetaθ が系統電圧位相に追従する。

PLL が系統の弱点になる: 系統が弱い（短絡容量 CCC が小さい、第6回 6.2.4 節）と、 インバータ自身の出力電流が系統電圧を動かしてしまい、 PLL が不安定になることがある。これを弱系統問題という。 再エネ比率が高い系統で顕在化する。

図 9.5　dq 変換。左の三相交流を、系統位相に同期して回る座標で見ると（右）d 軸と q 軸が一定値の直流量になる。直流であれば PI 制御で定常偏差なく制御できる。

9.2.5 グリッドフォロイングとグリッドフォーミング

系統連系インバータには 2 つの根本的に異なる制御思想がある。

項目 グリッドフォロイング（電流制御型） グリッドフォーミング（電圧制御型）
振る舞い 電流源 電圧源
系統電圧 PLL で追従する 自ら作る
単独運転 不可（系統がないと動けない） 可能
慣性 なし 模擬できる
系統への寄与 電力を注入するだけ 電圧・周波数を支える
現在の普及 ほぼ全ての太陽光 PCS 研究・実証段階、一部実用化
弱系統での安定性 低い 高い

なぜ従来はグリッドフォロイングだったのか:

  1. 制御が単純で安価
  2. 系統が十分強い（同期発電機が多数）ことを前提にできた
  3. 単独運転を防止することが規程で求められてきた（9.2.6 節）

なぜグリッドフォーミングが必要になったのか:

再エネ比率が上がると、系統に「電圧・周波数を作る主体」が足りなくなる。 全員が追従者（フォロワー）では、誰も基準を作れない。

同期発電機が減るなら、インバータが同期発電機の役割を担うしかない\boxed{\text{同期発電機が減るなら、インバータが同期発電機の役割を担うしかない}}同期発電機が減るなら、インバータが同期発電機の役割を担うしかない​

仮想同期発電機（VSG: Virtual Synchronous Generator）: グリッドフォーミング制御の代表例。インバータの中で動揺方程式を数値的に解き、 その解に従って出力電圧の位相・振幅を決める。

2Hvirtualω0d2δdt2=Pref−Pout−Ddδdt\frac{2H_\text{virtual}}{\omega_0}\frac{d^2\delta}{dt^2} = P_\text{ref} - P_\text{out} - D\frac{d\delta}{dt}ω0​2Hvirtual​​dt2d2δ​=Pref​−Pout​−Ddtdδ​

第7回で学んだ動揺方程式そのものである。 HvirtualH_\text{virtual}Hvirtual​ はソフトウェアで設定できるので、 物理的な回転体がなくても慣性を持たせられる。

ただし限界がある: 同期発電機の慣性は回転体の運動エネルギーという 実体のあるエネルギーに裏付けられている。 仮想慣性は直流側（蓄電池や太陽光）からエネルギーを取り出すので、 直流側にエネルギー的な余裕がなければ機能しない。 太陽光単体では最大出力点で運転しているため出力を増やす余地がなく、 慣性を出すにはあらかじめ出力を絞っておく（＝発電機会の損失）か、 蓄電池を併設する必要がある。

図 9.6　グリッドフォロイング（電流源・PLL で追従）とグリッドフォーミング（電圧源・自分で周波数と電圧を作る）の違い。同じハードウェアでも制御の考え方で電源の性格が変わる。

9.2.6 単独運転検出

単独運転（islanding）: 系統側が停電したにもかかわらず、 分散型電源が負荷に電力を供給し続け、系統の一部が孤立して運転を続ける状態。

なぜ危険か:

  1. 感電の危険 — 停電したと思って作業する人が感電する
  2. 機器の損傷 — 周波数・電圧が不安定になる
  3. 再閉路時の事故 — 系統復旧時に位相がずれたまま接続され、機器が破損する

このため系統連系規程では単独運転を検出して速やかに解列することが求められる。

検出方式:

分類 方式 原理
受動的方式 電圧位相跳躍検出 単独運転移行時の位相の飛びを検出
周波数変化率検出（RoCoF） df/dtdf/dtdf/dt の急変を検出
三次高調波電圧急増検出 変圧器の励磁電流由来の高調波を検出
能動的方式 無効電力変動方式 わずかに QQQ を変動させ、周波数の応答を見る
周波数シフト方式 周波数を意図的にずらそうとする
有効電力変動方式 PPP を変動させ電圧の応答を見る

受動的方式は系統に影響を与えないが、 不感帯（負荷と発電がちょうど釣り合うと検出できない）がある。 能動的方式は不感帯が小さいが、多数台が接続されると相互干渉する。 実際には両方を組み合わせて用いる。

ジレンマ: 単独運転検出は「系統が消えたら止まれ」という思想である。 しかしグリッドフォーミング（9.2.5 節）は「系統を作れ」という思想であり、 両者は正面から対立する。 今後の系統では、意図的なマイクログリッド運転（計画的な単独運転）を 許容する方向で規程の見直しが進んでいる。

図 9.7　単独運転の危険性。上位系統から切り離されても発電と消費がたまたま釣り合うと送電が続き、作業員の感電・機器の破損・再閉路時の位相不一致を招く。検出して停止させることが義務づけられている。

9.2.7 インバータによる電圧制御 — 第6回の問題への解答

第6回 6.3.4 節の演習で、太陽光を大量導入すると 末端母線の電圧が 1.05 p.u. を超える現象を観察した。 6.2.4 節の電圧感度の理論で、配電系統では R∼XR \sim XR∼X のため 有効電力の逆潮流だけでも電圧が上がることも確認した。

インバータはこれに対して 3 つの対策を提供できる。

(1) 力率一定制御（進み力率運転）

インバータを力率 1 ではなく、進み力率（Q<0Q < 0Q<0、無効電力を吸収）で運転する。 日本では力率 0.95（進み）が標準的に採用されている。

Q=−Ptan⁡(arccos⁡0.95)=−0.329 PQ = -P\tan(\arccos 0.95) = -0.329\,PQ=−Ptan(arccos0.95)=−0.329P

第6回の ΔVr,Q\Delta V_{r,Q}ΔVr,Q​ の式より、QQQ を吸収すれば電圧が下がる。

長所 短所
実装が単純、追加機器不要 電圧が問題ない時も常に QQQ を吸収し損失が増える
全台一律で運用できる インバータ容量の一部を QQQ に使うため PPP の余地が減る

(2) 電圧無効電力制御（Volt-Var 制御）

自端の電圧を測定し、電圧が高いときだけ無効電力を吸収する。

   Q [p.u.]
    ↑
 +Q │‾‾‾╲
    │      ╲          ← 電圧が低い: Q を供給（電圧を上げる）
  0 ├────┼──╲────┼──────→ V [p.u.]
    │  0.95   ╲  1.05
 -Q │            ╲___  ← 電圧が高い: Q を吸収（電圧を下げる）

第6回 6.2.6 節の VQC を、インバータ自身が分散的に行うものである。 中央からの指令を待たずに応答できるため速い。

(3) 有効電力抑制（Volt-Watt 制御）

電圧が上限に達したら有効電力そのものを絞る。最終手段。 発電機会を失うので経済的損失が大きい。

優先順位: (2) → (1) → (3) の順に試みるのが合理的である。 まず無効電力で対応し、それでも足りなければ有効電力を絞る。

図 9.8　Volt-Var 制御（左）とその効果（右）。電圧が高いときだけ無効電力を吸収する折れ線制御により、6.6 kV 配電フィーダの太陽光連系可能量が 2.5 MW から 5.5 MW へ 2.2 倍に増える。

第8回で、再エネ増加により HsysH_\text{sys}Hsys​ と KGK_GKG​ の両方が下がることを見た。 インバータはこれにも対応できる。

9.3.1 PWM 波形と高調波スペクトル

"""第9回 デモ1: 三相 PWM の生成と FFT 解析"""
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Hiragino Sans', 'Yu Gothic', 'DejaVu Sans']

f1, V_dc = 60.0, 400.0
fs = 1_000_000.0                 # 解析用サンプリング
t = np.arange(0, 3/f1, 1/fs)

def three_phase_pwm(t, m_a, f_sw):
    """三相PWMの相電圧（V_dc/2 基準）と線間電圧を返す"""
    # 搬送波（三角波、-1〜+1）
    carrier = 2*np.abs(2*((t*f_sw) % 1.0) - 1.0) - 1.0
    legs = []
    for ph in [0, -2*np.pi/3, 2*np.pi/3]:
        ref = m_a*np.sin(2*np.pi*f1*t + ph)
        legs.append(np.where(ref > carrier, V_dc/2, -V_dc/2))
    v_ab = legs[0] - legs[1]     # 線間電圧
    return legs[0], v_ab

def thd_and_fundamental(sig, t, f1):
    N = len(sig)
    spec = np.abs(np.fft.rfft(sig))*2/N
    freqs = np.fft.rfftfreq(N, t[1]-t[0])
    k1 = np.argmin(np.abs(freqs - f1))
    V1 = spec[k1]
    mask = (freqs > f1*0.5) & (np.abs(freqs - f1) > f1*0.5) & (freqs < 100*f1)
    thd = np.sqrt(np.sum(spec[mask]**2))/V1*100
    return V1, thd, freqs, spec

fig, axes = plt.subplots(2, 2, figsize=(13, 7))
for col, f_sw in enumerate([1080.0, 3600.0]):     # m_f = 18, 60（3の倍数）
    v_a, v_ab = three_phase_pwm(t, 0.9, f_sw)
    V1, thd, freqs, spec = thd_and_fundamental(v_ab, t, f1)

    n = int(fs/f1*1.5)
    axes[0, col].plot(t[:n]*1000, v_ab[:n], lw=0.5, color="#888")
    axes[0, col].plot(t[:n]*1000, V1*np.sqrt(2)/np.sqrt(2)*np.sin(2*np.pi*f1*t[:n]+np.pi/6)*np.sqrt(2)/np.sqrt(2),
                      "r", lw=2, label="基本波成分")
    axes[0, col].set_title(f"線間電圧波形  $m_f$={f_sw/f1:.0f}, $f_{{sw}}$={f_sw:.0f} Hz")
    axes[0, col].set_xlabel("時間 [ms]"); axes[0, col].set_ylabel("電圧 [V]")
    axes[0, col].legend(fontsize=8); axes[0, col].grid(alpha=0.3)

    sel = freqs < 100*f1
    axes[1, col].stem(freqs[sel]/f1, spec[sel], markerfmt=" ", basefmt=" ")
    axes[1, col].set_xlabel("次数 ($f/f_1$)"); axes[1, col].set_ylabel("振幅 [V]")

9.3.3 Volt-Var 制御による電圧改善（第6回の続き）

"""第9回 デモ3: インバータの無効電力制御で連系可能量を増やす"""
import numpy as np
import pandapower as pp
import pandapower.networks as pn
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Hiragino Sans', 'Yu Gothic', 'DejaVu Sans']

PV_BUSES = [9, 10, 11, 12, 13]
V_LIMIT = 1.05

def max_pv_capacity(mode, pf=0.95):
    """電圧上限を超えない最大の太陽光導入率[%]を二分探索で求める"""
    lo, hi = 0.0, 400.0
    for _ in range(40):
        mid = (lo + hi)/2
        net = pn.case14()
        p_each = net.load.p_mw.sum()*mid/100/len(PV_BUSES)
        for b in PV_BUSES:
            if mode == "力率1":
                q = 0.0
            elif mode == "力率0.95進み":
                q = -p_each*np.tan(np.arccos(pf))
            else:                         # Volt-Var（簡易: 上限で最大吸収）
                q = -p_each*np.tan(np.arccos(0.90))
            pp.create_sgen(net, bus=b, p_mw=p_each, q_mvar=q)
        try:
            pp.runpp(net)
            ok = net.res_bus.vm_pu.max() <= V_LIMIT
        except pp.LoadflowNotConverged:
            ok = False
        if ok: lo = mid
        else:  hi = mid
    return lo

print(f"{'制御方式':>16} {'連系可能量[%]':>14} {'力率1比':>10}")
base = None
for mode in ["力率1", "力率0.95進み", "Volt-Var(0.90相当)"]:
    cap = max_pv_capacity(mode)
    if base is None: base = cap
    print(f"{mode:>16} {cap:14.1f} {cap/base:9.2f}x")

期待される結論: 無効電力を吸収させるだけで、 電圧制約による連系可能量が 1.3〜1.8 倍に増える。 設備を増やさずに再エネをより多く受け入れられるため、費用対効果が極めて高い。

9.3.4 合成慣性の効果（第8回の続き）

"""第9回 デモ4: 合成慣性による周波数応答の改善"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Hiragino Sans', 'Yu Gothic', 'DejaVu Sans']

F_N, S_sys, dP_step = 60.0, 1500.0, -250.0
K_G, K_L, T_gov = 90.0, 30.0, 8.0
H_low = 2.0                              # 再エネ大量導入時の慣性

def response(t, y, H_virtual, K_virtual, T_meas=0.15):
    """y=[dF, P_gov, dFdt_filtered]"""
    dF, P_gov, dFdt_f = y
    dP_gov = (-K_G*dF - P_gov)/T_gov
    # 合成慣性（df/dt に比例、測定遅れ T_meas の1次フィルタ経由）
    P_si = -2*H_virtual*S_sys/F_N*dFdt_f
    # 疑似ガバナ（droop）
    P_dr = -K_virtual*dF
    P_net = dP_step + P_gov + P_si + P_dr - K_L*dF
    ddF = F_N/(2*H_low*S_sys)*P_net
    d_dFdt_f = (ddF - dFdt_f)/T_meas     # df/dt の測定遅れ
    return [ddF, dP_gov, d_dFdt_f]

fig, ax = plt.subplots(figsize=(9.5, 5.5))
cases = [(0.0,  0.0, "#e63946", "対策なし（$H$=2.0 s）"),
         (2.0,  0.0, "#f4a261", "合成慣性のみ $H_v$=2.0 s"),
         (0.0, 80.0, "#e9c46a", "疑似ガバナのみ $K_v$=80 MW/Hz"),
         (2.0, 80.0, "#2a9d8f", "合成慣性＋疑似ガバナ")]

for Hv, Kv, color, label in cases:
    sol = solve_ivp(response, (0, 60), [0, 0, 0], args=(Hv, Kv),
                    t_eval=np.linspace(0, 60, 3000), rtol=1e-8, max_step=0.02)
    F = F_N + sol.y[0]
    ax.plot(sol.t, F, lw=2, color=color, label=f"{label}（最低 {F.min():.2f} Hz）")
    print(f"{label:28s}: nadir={F.min():.3f} Hz, 定常={F[-1]:.3f} Hz")

ax.axhline(F_N, color="k", lw=0.8, ls=":")
ax.axhline(57.0, color="r", ls="--", alpha=0.6, label="UFR 57.0 Hz")
ax.set_xlabel("時間 [s]"); ax.set_ylabel("系統周波数 [Hz]")

plt.tight_layout()

観察してほしいこと:

  • 合成慣性は最初の落ち方（RoCoF）を緩やかにするが、定常偏差は改善しない （df/dtdf/dtdf/dt が 0 になれば出力も 0 になるため）
  • 疑似ガバナは定常偏差を改善するが、初期の急落は防げない
  • 両方を入れると初期も定常も改善する

これは第8回の HHH（慣性）と KKK（系統定数）の役割の違いそのものである。

図 9.9　合成慣性の効果。H = 2.0 s の系統で 250 MW が脱落したとき、H_v = 3.0 s の合成慣性を入れると最低周波数が 56.52 → 57.23 Hz に改善する。最大 143 MW を数秒だけ出して時間を稼ぐ。

  2. 合成慣性で補うべき HvirtualH_\text{virtual}Hvirtual​ を求めよ。
  3. 合成慣性が出すべき最大電力を求めよ。

解答

(2) 実効的な慣性を 4.0 s にすればよいので

Hvirtual=4.0−1.5=2.5 sH_\text{virtual} = 4.0 - 1.5 = \boxed{2.5\ \text{s}}Hvirtual​=4.0−1.5=2.5 s​

(3) 合成慣性の出力は

考察: 156 MW という大きな出力を瞬時に出す必要がある。 これは蓄電池なら可能だが、太陽光単体では

  • 最大電力点で運転している → 出力を増やす余地がない
  • 増やすにはあらかじめ出力を絞っておく必要がある（発電機会の損失）

したがって現実的には蓄電池の併設が必要になる。 出力は大きいが継続時間は数秒なので、容量（kWh）よりも出力（kW）が 効くタイプの用途である。

9.6 まとめ

キーポイント

  • PWM は変調波と搬送波の比較でパルス幅を作る。 三相の線間電圧基本波実効値は VLL,1=0.612 maVdcV_{LL,1} = 0.612\,m_aV_\text{dc}VLL,1​=0.612ma​Vdc​（線形領域）。
  • mf=fsw/f1m_f = f_\text{sw}/f_1mf​=fsw​/f1​ を上げると高調波が高次に移りフィルタが小さくて済むが、 スイッチング損失が増える。mfm_fmf​ は 3 の奇数倍に選ぶと第3調波が相殺される。
  • dq 変換により三相交流が直流量になり、PI 制御で定常偏差なく制御できる。 ddd 軸を電圧に合わせれば id→Pi_d \to Pid​→P、iq→Qi_q \to Qiq​→Q で独立制御できる。 位相検出には PLL を使うが、弱系統では PLL 自体が不安定要因になる。
  • グリッドフォロイング（電流源・PLL 追従・慣性なし）が現在の主流。 グリッドフォーミング（電圧源・自ら電圧を作る・慣性を模擬できる）が 再エネ主力化に向けて必要になる。仮想同期発電機（VSG）は インバータ内部で第7回の動揺方程式を解く。
  • 単独運転検出は感電防止・機器保護・再閉路事故防止のために必須。 受動的方式（不感帯あり）と能動的方式（相互干渉あり）を併用する。 ただしグリッドフォーミング／マイクログリッドとは思想が対立する。
  • 第6回の電圧問題への解答: Volt-Var 制御（電圧が高いときだけ QQQ を吸収）で 連系可能量が 1.3〜1.8 倍に増える。設備増強より費用対効果が高い。
  • 第8回の周波数問題への解答: 合成慣性は RoCoF（初期の落ち方）を改善し、 疑似ガバナは定常偏差を改善する。両方必要。 ただし合成慣性は df/dtdf/dtdf/dt の測定遅れがあり、真の慣性とは等価でない。 また直流側にエネルギー余裕（蓄電池）がなければ機能しない。

次回への橋渡し

第9回までで、電力系統の物理と制御は一通り扱った。 第1〜3回で基礎、第4〜6回で潮流計算、第7〜8回でダイナミクス、 第9回でパワーエレクトロニクスである。

しかし再生可能エネルギーには、これまで扱わなかった決定的な性質がある。 出力が天候によって決まり、こちらの意思で制御できないという点である。

第10回からは視点を変え、「予測」を扱う。 まず気象予測の基礎と、それが太陽光・風力の発電量にどう結びつくかを学ぶ。 第1回で見た「風力出力は風速の 3 乗に比例する」という非線形性が、 ここで予測の難しさとして再登場する。
