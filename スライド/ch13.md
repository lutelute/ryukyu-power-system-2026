# GNN の 1 層 — 自分と隣の平均を混ぜる

<div class="eq-main">

$$h_i^{(l+1)} = \sigma\!\left( W_\text{self}\, h_i^{(l)} + W_\text{nbr}\, \frac{1}{|N(i)|}\sum_{j \in N(i)} h_j^{(l)} \right)$$

</div>

<div class="eq-desc">
  <span class="sym">$N(i)$</span>
  <span>母線 i の隣接母線。Y_bus の非零パターンがそのまま隣接関係になる</span>
  <span class="sym">$W_\text{self}, W_\text{nbr}$</span>
  <span>全ノード共通の重み。だから母線番号の順序に依らず、大きな系統にも使い回せる</span>
  <span class="sym">$l$</span>
  <span>層数：l 層で l ホップ先の情報が届く。潮流の影響範囲に合わせて 2〜4 層</span>
  <span class="sym">$h^{(l)}$</span>
  <span>用途：潮流の近似、状態推定の初期値、N-1 のスクリーニング</span>
</div>

<!-- note: 平均を取るのは「隣が何本あっても同じ扱い」にするため。和にすると次数の大きいノードだけ値が大きくなる。 -->

# 導出 — 加重最小二乗（WLS）

<div class="sec">
  <span class="sec-title">① 計測は誤差を含む｜z = h(x) + e</span>
  <span class="sec-body">計測 z（潮流・電圧・注入）と、状態 x（各母線の電圧の大きさと位相）を結ぶのが潮流の式 h(x)。計測誤差 e の分散は計器ごとに違う。</span>
</div>

<div class="sec">
  <span class="sec-title">② 精度の良い計測を重く扱う｜J(x) = Σ (z_i − h_i(x))² / σ_i²</span>
  <span class="sec-body">σ が小さい（正確な）計測ほど、ずれたときのペナルティが大きい。この J を最小にする x を探す。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 反復で解く｜(HᵀR⁻¹H) Δx = HᵀR⁻¹(z − h(x))</span>
  <span class="sec-body">H は h の偏微分（ヤコビアン）。形は第5回のニュートン・ラフソン法と同じで、**計測が未知数より多い**（冗長）ことが前提になる。</span>
</div>

<!-- note: 冗長性があるから、誤差を平均化でき、不良データも見つけられる。この 2 つが状態推定の存在理由。 -->

---

# 精度の違う計測をどう混ぜるか

![w:1150](../図/ch13_state_estimation.png)

<div class="caption">「たくさん測って平均する」のではなく「精度に応じて重みをつけて混ぜる」（左が目的関数、右が真値からの誤差）。それだけで推定は大きく改善する。</div>

<!-- note: 重みは 1/σ²。PMU（同期フェーザ計測）は σ が小さいので、少数でも大きく効く。　図の要点：計測1（σ=0.01）と計測2（σ=0.03）／単純平均：0.9545／WLS：0.9509（真値 0.95）／誤差は約 4 分の 1 に -->

# 不良データを見つける

## 読み方｜推定値との残差。しきい値を超えたものが疑わしい

![w:620](../図/ch13_bad_data.png)

<div class="fs-points">
- 冗長な計測があるから残差が計算できる
- 3σ を超えた計測を除いて再推定
- 故障した計器・通信エラーを検出
- 除いた後にもう一度 WLS を回す
</div>

<div class="fs-conclusion">状態推定は「推定する」だけでなく「計測を検品する」機能を持つ。EMS のすべての計算はこの後に続く。</div>

# なぜそう考えるか — 正常を学ぶ・物理を残す

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ「正常」を学ぶのか</span>
  <span class="bk-body">事故のデータは希少で、未知の故障は学習できない。正常だけを学び、そこからの距離で検出すれば、見たことのない異常も拾える。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ物理を捨てないのか</span>
  <span class="bk-body">電力系統には確立した物理モデルがある。PINN は損失に方程式の残差を足し、データが薄い領域でも物理に沿った答えを出す。純データ駆動は学習範囲の外で崩れる。</span>
</div>

<div class="bk alert">
  <span class="bk-title">実務の型</span>
  <span class="bk-body">AI でスクリーニング → 厳密計算で確認。AI 単独で遮断器は操作しない。</span>
</div>

</div>
