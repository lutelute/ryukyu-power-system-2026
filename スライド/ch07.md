# Ⅱ. 動揺方程式

## 電気の式ではなく、回転体の運動方程式

---

<!-- _class: sections -->
<!-- build -->

# 導出 — 動揺方程式はニュートンの運動方程式

<div class="sec">
  <span class="sec-title">① 回転体の運動方程式｜J θ'' = T_m − T_e</span>
  <span class="sec-body">慣性モーメント J のロータに、機械トルク T_m と電気トルク T_e がかかる。回転版の F = ma そのもの。</span>
</div>

<div class="sec">
  <span class="sec-title">② トルクを電力に｜P = ωT なので両辺を ω で割る</span>
  <span class="sec-body">定格速度の近くでは ω ≈ ω₀ とみなせるので、**(Jω₀) δ'' = P_m − P_e**。角度は電気角の相差角 δ に取り直す。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 単位法へ｜定格容量で割り、H = (½Jω₀²)/S_rated を使う</span>
  <span class="sec-body">**(2H/ω₀) δ'' = P_m − P_e**。教科書の M = 2H/ω₀ はこの係数。H は「定格出力で何秒回り続けられるか」で、単位は秒。</span>
</div>

<!-- note: ③で H の意味を強調する。H = 4 s なら、入力が止まっても運動エネルギーだけで 4 秒間は定格出力を出せる、という貯金の大きさ。 -->

---

<!-- _class: equation -->

# 動揺方程式 — 今日の主役

<div class="eq-main">

$$\frac{2H}{\omega_0}\,\frac{d^2\delta}{dt^2} = P_m - P_e - D\,\frac{d\delta}{dt}, \qquad P_e = P_\text{max}\sin\delta$$

</div>

<div class="eq-desc">
  <span class="sym">$P_m - P_e$</span>
  <span>加速電力 P_a。入る力と出る力の差がロータを加速・減速させる</span>
  <span class="sym">$2H/\omega_0$</span>
  <span>慣性（質量に相当）。教科書の M。大きいほど δ はゆっくり動く</span>
  <span class="sym">$P_\text{max}\sin\delta$</span>
  <span>第3回の送電電力式。三相短絡の間は P_e = 0 になる</span>
  <span class="sym">$D$</span>
  <span>制動係数。振れを減衰させる。PSS はこれを実質的に増やす装置</span>
</div>

<!-- note: D は本来小さい。だから事故後の振動はなかなか収まらない。PSS の効果は後で図で見せる。 -->

# Ⅲ. 等面積法

## 貯めたエネルギーを吐き出せるか

---

<!-- _class: sections -->
<!-- build -->

# 導出 — 面積がエネルギーになる理由

<div class="sec">
  <span class="sec-title">① 動揺方程式に δ' を掛けて積分する</span>
  <span class="sec-body">(2H/ω₀) δ'δ'' = (P_m − P_e) δ'。左辺は (H/ω₀) d(δ'²)/dt で、**運動エネルギーの時間変化**そのもの。</span>
</div>

<div class="sec">
  <span class="sec-title">② dt を dδ に変えると面積になる</span>
  <span class="sec-body">両辺を時間で積分し δ' dt = dδ を使うと **(H/ω₀)(δ')² = ∫(P_m − P_e) dδ**。右辺は P–δ 平面の面積。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 戻れる条件｜どこかで δ' = 0 になること</span>
  <span class="sec-body">加速で貯めた面積 A1 を、減速の面積 A2 で使い切れば速度が 0 になり戻ってくる。**A1 = A2 が境目**。</span>
</div>

<!-- note: 「面積＝エネルギー」は②で出る。ここが等面積法の核心なので、板書で δ' を掛ける操作を見せる。 -->

---

<!-- _class: figure-story -->
<!-- source: コード/fig_ch07.py -->

# 等面積法 — A1 と A2 が釣り合う角度

## 読み方｜赤が事故中に貯める面積、緑が除去後に吐き出せる面積

![w:640](../図/ch07_equal_area.png)

<div class="fs-points">
- δ₀ = 23.6°（P_m = P_e の運転点）
- δ_max = 180° − δ₀ = 156.4°
- A1 = A2 となる **δ_cr = 89.4°**
- ここまでに切れば戻れる
</div>

<div class="fs-conclusion">δ_cr の式に H は出てこない。臨界「角」は P–δ 平面の幾何だけで決まる。</div>

<!-- note: δ_max より右では P_e < P_m に戻ってしまうので、そこを速度を持ったまま越えたら二度と戻れない。 -->

---

<!-- _class: equation -->

# 臨界除去角と臨界除去時間

<div class="eq-main">

$$\cos\delta_\text{cr} = \frac{P_m(\delta_\text{max} - \delta_0) + P_\text{max}\cos\delta_\text{max}}{P_\text{max}}, \qquad t_\text{cr} = \sqrt{\frac{4H(\delta_\text{cr}-\delta_0)}{\omega_0 P_m}}$$

</div>

<div class="eq-desc">
  <span class="sym">$\delta_\text{cr}$</span>
  <span>臨界除去角。A1 = A2 を解いた結果。角度はラジアンで代入する</span>
  <span class="sym">$t_\text{cr}$</span>
  <span>臨界除去時間。事故中は加速電力が一定なので等加速度運動になる</span>
  <span class="sym">$\sqrt{H}$</span>
  <span>H が半分になると t_cr は 0.707 倍。角度は変わらず時間だけ縮む</span>
  <span class="sym">$P_e = 0$</span>
  <span>条件：三相短絡（事故中 P_e = 0）で、除去後は元の P_max に戻る場合</span>
</div>

<!-- note: 度のまま代入する誤りが毎年出る。ω₀ = 2π×60 = 377 rad/s も確認させる。 -->

---

# 例題 1 — t_cr を手で出す

<div class="st-container">

<div class="st-step">
  <span class="st-num">1</span>
  <span class="st-title">運転点</span>
  <span class="st-body">δ₀ = asin(0.8/2.0) = 0.412 rad = 23.6°、δ_max = π − δ₀ = 2.730 rad</span>

# なぜそう考えるか — H は角度でなく時間に効く

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ δ_cr は H に依らないのか</span>
  <span class="bk-body">等面積法はエネルギーの釣り合いで、面積は P–δ 平面の幾何だけで決まる。H は「その角度に何秒で着くか」にしか関わらない。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ t_cr は √H に比例するのか</span>
  <span class="bk-body">事故中は加速電力が一定なので等加速度運動。δ − δ₀ = (ω₀P_m/4H)t² となり、同じ角度に達する時間は √H に比例する。H が半分なら 0.707 倍。</span>
</div>

<div class="bk alert">
  <span class="bk-title">落とし穴</span>
  <span class="bk-body">角度を度のまま代入しない。δ はラジアン、ω₀ = 2π×60 = 377 rad/s。</span>
</div>

# 持ち帰る 3 点

<div class="ta-main">安定度は回転体の力学。貯めた勢いを吐き出せるかを面積で比べ、その時間の余裕を H が決める</div>

<div class="ta-points">
<li>動揺方程式 (2H/ω₀)δ″ = P_m − P_max sinδ。H は「勢いの貯金」で単位は秒</li>
<li>等面積法：A1 = A2 で δ_cr = 89.4°、t_cr = 247 ms。数値積分とも一致</li>
<li>対策は A1 を減らす（高速除去）か A2 を増やす（P_max 増）。慣性低下は余裕を削る</li>
</div>
