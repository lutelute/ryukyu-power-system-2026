<!-- _class: statement -->

電力系統は「昇圧して運び、降圧して使う」階層構造。送電損失は電圧の 2 乗に反比例するから、高い電圧で運ぶ。母線が節点、線路が枝で、電流は経路を選ばずインピーダンスの逆比で分かれる。

# 変圧器 — 電圧 a 倍、電流 1/a 倍

## 読み方｜275/66 kV・100 MVA。巻数比 a = 4.17 で電流は 210 A から 875 A に増える

![w:600](../図/ch02_transformer.png)

<div class="fs-points">
- 巻数比 a = N₁/N₂ = V₁/V₂ = 4.17
- I₂ = a I₁：210 A → 875 A
- Z₂ は一次から見ると a² = 17.4 倍
- 単位法なら両側で 0.184（第3回）
</div>

<div class="fs-conclusion">変圧器を挟むたびに a² の換算が要る。これが面倒だから系統解析は単位法（p.u.）で書く。第3回の動機はここ。</div>

<!-- note: 理想変圧器は容量が保存（√3 V₁ I₁ = √3 V₂ I₂）。「電圧を 4 倍にしたら電流は 1/4、損失は 1/16」が次の章の伏線。 -->

# 例題 1 — 変圧器の巻数比と電流

<div class="st-container">

<div class="st-step">
  <span class="st-num">1</span>
  <span class="st-title">巻数比</span>
  <span class="st-body">a = V₁/V₂ = 275/66 = 4.17。N₁/N₂ も同じ値</span>
</div>

<div class="st-step">
  <span class="st-num">2</span>
  <span class="st-title">一次電流</span>
  <span class="st-body">I₁ = S/(√3 V₁) = 100 × 10⁶/(√3 × 275 × 10³) = 210 A</span>

<div class="st-step">
  <span class="st-num">3</span>
  <span class="st-title">二次電流</span>

  <span class="st-title">インピーダンス換算</span>

# 導出 — 損失は電圧の 2 乗に反比例する

![w:1150](../図/ch02_deriv_loss_1.png)

<div class="caption">送る電力 P と線間電圧 V を決めると電流が決まる：I = P/(√3 V cosφ)。同じ P なら、電流は V に反比例する。</div>

# 予備率 10% でも N-1 で 100 MW 足りない

## 読み方｜需要 1,500 MW に供給力 1,650 MW。最大機 250 MW が抜けると 1,400 MW で需要を下回る

![w:600](../図/ch02_reserve.png)

<div class="fs-points">
- 予備率 = (1,650 − 1,500)/1,500 = 10%
- 最大機脱落後：1,400 MW → −6.7%
- N-1 を満たすには 1,750 MW（16.7%）
- 独立系統は融通で埋められない
</div>

<div class="fs-conclusion">N-1 基準＝「どの 1 設備が抜けても供給を続ける」。連系のある本土は隣から借りられるが、沖縄は自前の予備力で持つしかない。</div>

<!-- note: 予備率の分母は需要。「最大機が大きいほど必要な予備率が高い」= 離島で大型機を入れにくい理由。 -->

# なぜそう考えるか — 交流・周波数・直流

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ交流が主流なのか</span>
  <span class="bk-body">変圧器で電圧を自在に上げ下げできるから。損失を下げるには高電圧、使うには低電圧。この両立は変圧器なしには成り立たない。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ 50 Hz と 60 Hz に分かれたのか</span>
  <span class="bk-body">明治期に東京はドイツ製、大阪は米国製の発電機を導入した歴史の名残。統一の費用が大きく、変換設備でつないでいる。</span>
</div>

<div class="bk alert">
  <span class="bk-title">直流送電（HVDC）の出番</span>
  <span class="bk-body">変圧は苦手だが、長距離（架空線 600 km・ケーブル 50 km 超）・海底ケーブル・非同期連系では有利。北海道–本州、紀伊水道はこれ。</span>
</div>

# 持ち帰る 3 点

<div class="ta-main">高電圧は損失対策。系統は「上げて運び、下げて使う」階層で、母線がその節点</div>

<div class="ta-points">
<li>損失 = RP²/(V² cos²φ)。66 → 500 kV で 57 分の 1、力率 0.8 で 1.56 倍</li>
<li>並列線路は Z の逆比で分かれ、1 本落ちれば残りが全電流を負う（→ N-1、潮流計算）</li>
<li>沖縄は完全独立・小規模。予備力も慣性も自前で持つ（第8回・第15回）</li>
</div>
