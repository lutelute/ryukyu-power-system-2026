# 導出 — 等 λ 法

<div class="sec">
  <span class="sec-title">① 問題を書く｜総費用を最小に、需給は一致</span>
  <span class="sec-body">min Σ C_i(P_i)、条件 Σ P_i = D。制約付き最小化なのでラグランジュの未定乗数法を使う。</span>
</div>

<div class="sec">
  <span class="sec-title">② 微分する｜L = Σ C_i(P_i) − λ(Σ P_i − D)</span>
  <span class="sec-body">P_i で偏微分して 0 と置くと **dC_i/dP_i = λ**（すべての i で同じ）。これが等 λ 条件である。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 直感で確かめる｜λ が違えば動かす余地がある</span>
  <span class="sec-body">もし機 1 の λ が機 2 より高ければ、機 1 を 1 MW 減らして機 2 を 1 MW 増やすだけで総費用が下がる。**下がらなくなる点が等しい点**。λ は「あと 1 MWh の値段」。</span>
</div>

<!-- note: ③の説明が最も腑に落ちる。数式より先にこちらを話してもよい。 -->

<!-- _class: equation -->

# OPF — 潮流方程式と系統制約を足す

<div class="eq-main">

$$\min \sum_i C_i(P_{Gi}) \quad \text{s.t.}\quad
\begin{cases}
\text{潮流方程式（第4回）} \\
P_{Gi}^{\text{min}} \le P_{Gi} \le P_{Gi}^{\text{max}} \\
V_i^{\text{min}} \le V_i \le V_i^{\text{max}} \\
|P_{ij}| \le P_{ij}^{\text{max}}
\end{cases}$$

</div>

<div class="eq-desc">
  <span class="sym">$\text{s.t.}$</span>
  <span>ELD との違い：需給バランスだけでなく、電圧・線路容量・安定度も守る</span>
  <span class="sym">AC-OPF</span>
  <span>厳密だが非線形・非凸。局所解に落ちることがある</span>
  <span class="sym">DC-OPF</span>
  <span>第4回の 3 近似で線形化。線形計画なので数万変数でも秒で解ける</span>
  <span class="sym">$P_{ij}$</span>
  <span>用途：市場の約定計算・混雑管理は DC-OPF、詳細検討は AC-OPF</span>
</div>

<!-- note: 第4回の直流法がここで効いてくる。近似だからこそ、市場という「毎日必ず解く」場面で使える。 -->

# 導出 — LMP はなぜ地点で違うのか

<div class="sec">
  <span class="sec-title">① LMP の定義｜その地点で需要を 1 MW 増やしたときの総費用の増分</span>
  <span class="sec-body">λ と同じ考え方を「地点ごと」に適用する。混雑がなければ、どの地点で増やしても同じ機が応じるので **全地点で同じ値**になる。</span>
</div>

<div class="sec">
  <span class="sec-title">② 混雑すると届かない｜安い電気が入ってこられない</span>
  <span class="sec-body">線路が満杯だと、その先で 1 MW 増やす需要は**その地点側の高い電源**で賄うしかない。だから LMP がそこだけ上がる。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 分解すると 3 成分｜LMP = λ + 混雑 + 損失</span>
  <span class="sec-body">系統全体の λ に、混雑成分と損失成分が地点ごとに乗る。**混雑レント = (LMP差) × 潮流** が、送電線を増強する価値の目安になる。</span>
</div>

<!-- note: ②が直感の核心。「安い電気が届かないから高い電気を使う」という当たり前のことを価格が表している。 -->

# なぜそう考えるか — 等 λ・線形化・二値

<div class="bk-container">

<div class="bk theorem">
  <span class="bk-title">なぜ「等しい」が最適なのか</span>
  <span class="bk-body">ラグランジュ乗数 λ は「需要を 1 MW 増やしたときの総費用の増分」。どの機で増やしても同じでなければ、安い方へ移す余地が残っている。</span>
</div>

<div class="bk example">
  <span class="bk-title">なぜ DC-OPF は線形計画になるのか</span>
  <span class="bk-body">直流法の 3 近似（|V| = 1、R = 0、sin θ ≈ θ）で潮流制約が線形になる。費用も区分線形にすれば完全な LP で、数万変数でも秒で解ける。</span>
</div>

<div class="bk alert">
  <span class="bk-title">ユニットコミットメント（UC）</span>
  <span class="bk-body">「どの機を起動するか」は 0/1 の変数。混合整数計画で NP 困難。起動費用と最低運転時間が絡む。</span>
</div>

</div>

# よくある誤解 — 3 つとも「限界費用」を見落としている

![w:1150](../図/ch14_myth.png)

<div class="caption">3 つとも根は同じ。限界費用は出力とともに動き、混雑すれば地点によっても動く。「一定」だと思っている限り、この 3 つの誤解から抜けられない。</div>

# 持ち帰る 3 点

<div class="ta-main">最適は「揃える」。λ を揃え、制約を足して OPF、混雑は価格に表れる</div>

<div class="ta-points">
<li>等 λ 法：dC_i/dP_i = λ。上限に当たった機は固定して残りで揃える</li>
<li>OPF = ELD + 潮流 + 制約。DC-OPF は第4回の近似で線形計画になる</li>
<li>LMP = λ + 混雑 + 損失。混雑レントが送電線増強の価値を測る</li>
</div>
