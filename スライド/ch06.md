# 導出 — 電圧降下の近似式

<div class="sec">
  <span class="sec-title">① 線路を流れる電流｜受電端で P + jQ を消費する</span>
  <span class="sec-body">受電端電圧を V、消費を P + jQ とすると I = (P − jQ)/V*。線路は R + jX。</span>
</div>

<div class="sec">
  <span class="sec-title">② 電圧降下｜ΔV = (R + jX)·I を実部と虚部に分ける</span>
  <span class="sec-body">ΔV = (RP + XQ)/V + j(XP − RQ)/V。位相差が小さければ **大きさの変化は実部だけ**で決まる。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 実用形｜ΔV ≈ (RP + XQ)/V</span>
  <span class="sec-body">送電線は X ≫ R なので **XQ が支配**。配電線は R が大きく **RP も効く**。だから太陽光の逆潮流（P &lt; 0）で電圧が上がる。</span>
</div>

<!-- note: ②から③へ落とすとき「虚部は位相をずらすだけ」と言う。第3回の P–δ / Q–V 分離と同じ構造。 -->

---

<!-- source: コード/fig_ch06.py -->

# 近似式は実用十分 — 逆潮流では符号が反転する

# Ⅲ. 限界を知る

## 鼻先は「解が消える点」

---

<!-- _class: sections -->
<!-- build -->

# 導出 — PV カーブの鼻先

<div class="sec">
  <span class="sec-title">① 2 母線・R = 0・力率 1｜送電端 V_s、受電端 V_r、リアクタンス X</span>
  <span class="sec-body">P = V_sV_r sinδ / X、そして V_r の式を整理すると **V_r⁴ − V_s²V_r² + (XP)² = 0**。V_r² の 2 次方程式になる。</span>
</div>

<div class="sec">
  <span class="sec-title">② 解が 2 つ｜判別式 V_s⁴ − 4(XP)² ≥ 0</span>
  <span class="sec-body">上枝（運用点）と下枝（不安定）。同じ P に対して電圧が 2 通りある。</span>
</div>

<div class="sec">
  <span class="sec-title">③ 鼻先｜判別式が 0 になる点</span>
  <span class="sec-body">**P_max = V_s²/(2X)**、そのとき **V_r = V_s/√2 = 0.707 V_s**。これを超えると解が存在しない。</span>
</div>

<!-- note: 「解が無い」＝計算機のバグではなく物理。NR 法は無い解を探して発散する。 -->

# 例題 2 — 逆潮流で電圧はどう動くか

<div class="st-container">

<div class="st-step">
  <span class="st-num">1</span>
  <span class="st-title">条件</span>
  <span class="st-body">R = 0.10、X = 0.30 p.u.、送電端 1.00 p.u.、太陽光 0.4 p.u. が逆潮流</span>
</div>

<div class="st-step">
  <span class="st-num">2</span>
  <span class="st-title">力率 1</span>
  <span class="st-body">P = −0.4、Q = 0 → ΔV = (0.1×(−0.4) + 0)/1 = −0.040 → 1.040 p.u.</span>
</div>

<div class="st-step">
  <span class="st-num">3</span>
  <span class="st-title">力率 0.95 で Q を吸う</span>
  <span class="st-body">Q = +0.4×tan(18.2°) = +0.131 → ΔV = (−0.04 + 0.30×0.131)/1 = −0.001</span>
</div>

<div class="st-step">
  <span class="st-num">4</span>
  <span class="st-title">意味</span>
  <span class="st-body">RP の上昇分を XQ で打ち消した。X が大きい系統ほどこの対策が効く</span>
</div>

</div>

<!-- note: 学生に 3 を計算させる。tan(acos 0.95) = 0.329 を使う。X/R が大きいほど少ない Q で打ち消せる。 -->

# 持ち帰る 3 点

<div class="ta-main">解いたら読む。電圧は Q が決め、鼻先は解の消える点。つなぐ場所と力率が連系可能量を決める</div>

<div class="ta-points">
<li>ΔV ≈ (RP + XQ)/V。配電線は R も効き、逆潮流は電圧を上げる</li>
<li>電圧感度 ρ ≈ 1/S_sc。末端ほど柔らかく、早く限界に当たる</li>
<li>PV カーブの鼻先 P_max = V²/2X。力率 0.95 で連系可能量が 2.2 倍</li>
</div>
