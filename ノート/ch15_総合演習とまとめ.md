## まず直感で（3 分でつかむ）

> **📌 一言でいうと**：沖縄本島に太陽光を何 MW まで入れられるか。答えは 6 つの上限の最小値で決まり、対策は「今の律速」に打つ。

> **🪄 たとえ話：樽の一番低い板**
>
> | 樽 | 連系可能量 |
> |:--|:--|
> | 樽に入る水は **一番低い板** で決まる | 連系可能量 = **min(6 つの上限)** |
> | 高い板を伸ばしても水は増えない | 律速でない制約への対策は無駄 |
> | 低い板を伸ばすと **次に低い板** が効く | 対策すると **律速が移る** |
> | 板は 6 枚 | 電圧・容量・N-1・周波数・安定度・最低出力 |
> | 1 枚を伸ばす道具が別の板も伸ばすことがある | 蓄電池は周波数と最低出力の **2 枚** を伸ばす |
>
> 崩れる点：板は独立だが制約は連動する。太陽光を増やすと同期機が減り、周波数と安定度の板が同時に下がる。

> **📰 事例：2018年 北海道ブラックアウトの教訓**
> 大型電源への依存、系統の小ささ、そして **応援が来ない** こと。北海道は本州との直流連系が細く、沖縄は連系そのものが無い。周波数と慣性の議論（第8回）は、沖縄では設計の前提になる。

> **📰 事例：離島の実証と、本島の制約**
> 宮古島などの離島では再エネと蓄電池を組み合わせた実証が行われてきた。本島は 60 Hz の独立系統で、太陽光の拡大とともに火力の最低出力と慣性が制約として前に出てきている。今日の 6 制約はこの現実を式にしたもの。

> **🤔 この回の式で読むと**：沖縄は「日本で最も再エネ統合が難しい系統の 1 つ」。だからこそ教材として面白い。

> **🤔 なぜ最小値なのか**
> 制約は「すべて満たす」もの。1 つでも破れば運用できないので、上限の集合の最小値が答えになる。

> **🤔 なぜ対策で律速が移るのか**
> 対策は特定の板だけを伸ばす。伸ばした板が最小でなくなった瞬間、次に低い板が答えを決める。投資の順番は「今の律速」で決まる。

> **⚠ 1 つの制約だけ見ない**
> 電圧が余裕でも周波数で入らない。系統計画は 6 枚の板を同時に見る仕事である。

**この回の地図**：Ⅰ 系統モデルと 6 つの制約 → Ⅱ 制約ごとに「どこで破れるか」を実計算する → Ⅲ 最小値を取り、律速を言う → Ⅳ 対策を打つと律速が移る — 投資の順番

### 本回の課題 — 沖縄本島系統の再エネ導入可能量を評価する

**「沖縄本島系統に、太陽光発電を何 MW まで導入できるか」**

この一見単純な問いに答えるには、本講義のほぼ全内容が必要になる。

| 制約 | 何で決まるか | 学んだ回 |
|:---|:---|:---|
| **電圧上限** | 逆潮流による電圧上昇 | 第3回、第6回、第9回 |
| **線路容量** | 潮流の過負荷 | 第4〜6回 |
| **N-1 基準** | 1 回線停止時にも耐えるか | 第2回、第15回 |

| **予測誤差** | 必要な予備力 | 第10〜12回 |

**どれか 1 つでも破れば導入できない。** 最も厳しい制約が導入可能量を決める。

|:---|:---|

## 15.3 実装

### 15.3.1 系統モデルの構築とベースケース

```python
"""第15回 総合演習: 沖縄本島系統モデル"""
import numpy as np
import pandas as pd
import pandapower as pp
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Hiragino Sans', 'Yu Gothic', 'DejaVu Sans']

S_BASE, V_BASE, F_N = 1500.0, 132.0, 60.0
H_SYS, PCT_K = 4.5, 1.0                       # [s], [%MW/0.1Hz]

def build_okinawa(pv_mw=0.0, pv_pf=1.0, pv_bus=4):
    """沖縄本島系統の簡略モデル。pv_mw で太陽光容量を指定"""
    net = pp.create_empty_network(f_hz=F_N, sn_mva=100.0)
    names = ["具志川", "牧港", "那覇", "中部", "北部"]
    buses = [pp.create_bus(net, vn_kv=V_BASE, name=n) for n in names]

    pp.create_ext_grid(net, bus=buses[0], vm_pu=1.02, name="具志川")
    pp.create_gen(net, bus=buses[1], p_mw=250.0, vm_pu=1.01, name="牧港",
                  min_p_mw=60.0, max_p_mw=400.0,
                  min_q_mvar=-120.0, max_q_mvar=150.0)

    for b, p, q in [(2, 400.0, 160.0), (3, 350.0, 140.0), (4, 150.0, 60.0)]:
        pp.create_load(net, bus=buses[b], p_mw=p, q_mvar=q, name=names[b])

    for f, t, L in [(0,1,15.0), (1,2,25.0), (2,3,20.0), (3,4,35.0), (0,4,45.0)]:
        pp.create_line_from_parameters(
            net, from_bus=buses[f], to_bus=buses[t], length_km=L,
            r_ohm_per_km=0.06, x_ohm_per_km=0.35, c_nf_per_km=9.0,
            max_i_ka=1.2, name=f"L{f+1}-{t+1}")

    if pv_mw > 0:
        q = 0.0 if pv_pf >= 1.0 else -pv_mw*np.tan(np.arccos(pv_pf))
        pp.create_sgen(net, bus=buses[pv_bus], p_mw=pv_mw, q_mvar=q, name="太陽光")
    return net

net = build_okinawa()
pp.runpp(net)

print("="*66)
print("Step 1: ベースケースの潮流計算")
print("="*66)
res = net.res_bus.copy()
res["名称"] = net.bus.name.values
res["判定"] = res.vm_pu.apply(lambda v: "★逸脱" if not (0.95 <= v <= 1.05) else "OK")
print(res[["名称","vm_pu","va_degree","p_mw","q_mvar","判定"]].round(4).to_string())

print("\n--- 線路 ---")
lr = net.res_line.copy()
lr["線路"] = net.line.name.values
print(lr[["線路","p_from_mw","q_from_mvar","pl_mw","loading_percent"]].round(3).to_string())

p_gen  = net.res_ext_grid.p_mw.sum() + net.res_gen.p_mw.sum()
p_load = net.res_load.p_mw.sum()
p_loss = net.res_line.pl_mw.sum()
print(f"\n総発電 {p_gen:.2f} MW / 総負荷 {p_load:.2f} MW / "
      f"損失 {p_loss:.3f} MW ({p_loss/p_load*100:.2f}%)")
print(f"最大線路負荷率: {net.res_line.loading_percent.max():.2f} %")
```

### 15.3.2 Step 2: N-1 事故解析

```python
"""第15回: N-1 事故解析"""
def n1_analysis(pv_mw=0.0, pv_pf=1.0, verbose=True):
    """全線路を1本ずつ開放して健全性を確認"""
    rows = []
    for idx in build_okinawa().line.index:
        net = build_okinawa(pv_mw, pv_pf)
        name = net.line.name[idx]
        net.line.at[idx, "in_service"] = False
        try:
            pp.runpp(net)
            rows.append({
                "開放線路": name,
                "収束": "○",
                "V最小": net.res_bus.vm_pu.min(),
                "V最大": net.res_bus.vm_pu.max(),
                "最大負荷率": net.res_line.loading_percent.max(),
                "損失[MW]": net.res_line.pl_mw.sum(),
            })
        except pp.LoadflowNotConverged:
            rows.append({"開放線路": name, "収束": "×",
                         "V最小": np.nan, "V最大": np.nan,
                         "最大負荷率": np.nan, "損失[MW]": np.nan})
    df = pd.DataFrame(rows)
    # 判定（事故時基準: 電圧 0.90〜1.10、負荷率 120% 以内）
    def judge(r):
        if r["収束"] == "×": return "★不収束"
        ng = []
        if r["V最小"] < 0.90: ng.append("低電圧")
        if r["V最大"] > 1.10: ng.append("過電圧")
        if r["最大負荷率"] > 120: ng.append("過負荷")
        return "OK" if not ng else "★" + "/".join(ng)
    df["判定"] = df.apply(judge, axis=1)
    if verbose:
        print("="*66)
        print(f"Step 2: N-1 事故解析（太陽光 {pv_mw:.0f} MW）")
        print("="*66)
        print(df.round(4).to_string(index=False))
        ng = (df.判定 != "OK").sum()
        print(f"\n→ N-1 基準を満たさないケース: {ng} / {len(df)} 件")
    return df

df_n1 = n1_analysis(0.0)
```

### 15.3.3 Step 3: 動特性の評価

```python
"""第15回: 同期安定度と周波数維持の評価"""
print("="*66)
print("Step 3: 動特性の評価")
print("="*66)

def dynamics_check(H_sys, pct_k, dP_trip=250.0, S_sys=S_BASE, F_n=F_N):
    K = pct_k/100*S_sys*10                            # [MW/Hz]
    rocof = F_n*(-dP_trip)/(2*H_sys*S_sys)
    dF_ss = -dP_trip/K
    return K, rocof, dF_ss

def transient_stability(H_sys, P_max=2.0, P_m=0.8, F_n=F_N):
    w0 = 2*np.pi*F_n
    d0 = np.arcsin(P_m/P_max)
    cos_cr = P_m/P_max*(np.pi - 2*d0) - np.cos(d0)
    d_cr = np.arccos(np.clip(cos_cr, -1, 1))
    t_cr = np.sqrt(4*H_sys*(d_cr-d0)/(w0*P_m))
    return np.rad2deg(d0), np.rad2deg(d_cr), t_cr

print("\n--- 同期安定度（第7回）---")
d0, dcr, tcr = transient_stability(H_SYS)
print(f"  初期相差角 δ0    = {d0:.2f}°")
print(f"  臨界除去角 δ_cr  = {dcr:.2f}°")
print(f"  臨界除去時間 t_cr = {tcr*1000:.1f} ms")
t_protect = 70.0
print(f"  実際の保護時間   = {t_protect:.0f} ms （リレー20 + 遮断器50）")
print(f"  判定: {'✅ 安定' if tcr*1000 > t_protect else '❌ 脱調'}  "
      f"（余裕 {(tcr*1000-t_protect)/(tcr*1000)*100:.1f}%）")

print("\n--- 周波数維持（第8回）---")
K, rocof, dF = dynamics_check(H_SYS, PCT_K)
print(f"  系統定数 K       = {K:.0f} MW/Hz")
print(f"  RoCoF            = {rocof:+.3f} Hz/s")
print(f"  定常周波数偏差   = {dF:+.3f} Hz  → 到達 {F_N+dF:.3f} Hz")
print(f"  UFR 整定 57.0 Hz に対する余裕: {F_N+dF-57.0:+.3f} Hz")
print(f"  判定: {'✅ UFR 不動作' if F_N+dF > 57.0 else '❌ 負荷遮断'}")

print("\n--- 再エネ導入による慣性・系統定数の低下 ---")
print(f"{'太陽光[MW]':>11} {'H_sys[s]':>10} {'K[MW/Hz]':>10} "
      f"{'RoCoF[Hz/s]':>13} {'到達F[Hz]':>11} {'t_cr[ms]':>10} {'判定':>8}")
for pv in [0, 100, 200, 300, 400, 500, 600]:
    # 太陽光が増えるとその分の同期機を停止 → H と K_G が下がる
    frac = min(pv/900.0, 0.75)                    # 同期機の停止割合
    H_new = H_SYS*(1-frac)
    K_new = K*(1 - 0.75*frac)                     # K_L 分は残る
    _, rc, dfs = dynamics_check(H_new, 1.0)
    K_new = max(K_new, 1e-6)
    dfs = -250.0/K_new
    rc  = F_N*(-250.0)/(2*max(H_new,1e-6)*S_BASE)
    _, _, tc = transient_stability(max(H_new, 0.1))
    ok = (F_N+dfs > 57.0) and (tc*1000 > t_protect)
    print(f"{pv:11d} {H_new:10.2f} {K_new:10.0f} {rc:13.3f} "
          f"{F_N+dfs:11.3f} {tc*1000:10.1f} {'✅' if ok else '❌':>8}")
```

    T_cell = T_air + (45-20)/800*G
    return np.maximum(capacity*(G/1000)*(1-0.004*(T_cell-25))*0.82, 0)

def find_limit(check_fn, lo=0.0, hi=1200.0, tol=1.0):
    """二分探索で制約を満たす最大容量を求める"""
    if not check_fn(lo): return 0.0
    while hi - lo > tol:
        mid = (lo+hi)/2
        if check_fn(mid): lo = mid
        else: hi = mid
    return lo

### 15.4.2 講義を貫く 3 本の柱

**柱 1: $P$ と $Q$ は別物である**

第3回で導いた

$$P = \frac{V_sV_r}{X}\sin\delta, \qquad Q = \frac{V_sV_r\cos\delta - V_r^2}{X}$$

がすべての出発点だった。

| | 有効電力 $P$ | 無効電力 $Q$ |
|:---|:---|:---|
| 支配する量 | **相差角 $\delta$** | **電圧の大きさ** |
| 現れる問題 | 周波数（第8回）、安定度（第7回） | 電圧（第6回） |
| 性質 | **系統全体で共通**（周波数） | **局所的**（遠くへ運べない） |
| 制御 | ガバナ、LFC、ELD | AVR、調相設備、VQC |
| 計算上の帰結 | ヤコビアンの $\mathbf{H}$ ブロック | $\mathbf{L}$ ブロック |
| 高速化 | 高速デカップル法（第5回） | 同左 |

**柱 2: 慣性という見えない資産**

第7回で導入した $H$ が、その後ずっと効いてきた。

| 回 | $H$ が効く場面 |
|:--:|:---|
| 第7回 | $t_\text{cr}\propto\sqrt{H}$ — 保護に許される時間 |
| 第8回 | $dF/dt \propto 1/H$ — 周波数の落ちる速さ |
| 第9回 | 合成慣性・グリッドフォーミングで模擬する |
| 第13回 | AI 制御に求められる応答速度が上がる |
| 第15回 | 再エネ導入可能量の律速要因になりうる |

**インバータ電源は $H = 0$**。この 1 点が、再エネ大量導入の技術的課題の
かなりの部分を説明する。

**柱 3: 沖縄という題材**

| 特性 | 帰結 | 扱った回 |
|:---|:---|:--:|
| **完全独立系統** | 連系線の応援がない。$\Delta F = \Delta P/K$ の分母が小さい | 第2, 8回 |
| **小規模** | $K$ が小さく $H_\text{sys}S_\text{sys}$ も小さい | 第2, 7, 8回 |
| **亜熱帯・高温** | 太陽光の温度損失が大きい | 第10回 |
| **高湿度** | 需要予測に不快指数が必要 | 第11回 |
| **島嶼で地理的に狭い** | 予測の平滑化効果が働かない | 第10回 |
| **台風** | カットアウトによる出力の不連続 | 第10回 |

沖縄は**再エネ統合の難しさが凝縮された系統**であり、
だからこそ**世界的にも先端の研究対象**である。
ここで有効な技術は、他の島嶼系統や、
将来の低慣性化した本土系統にも適用できる。

## 15.6 おわりに

### 本講義で伝えたかったこと

**1. 電力系統は物理法則に支配されている**

キルヒホッフの法則、エネルギー保存則、熱力学第二法則、回転体の運動方程式。
どんなに高度な AI を使っても、これらを無視することはできない。
第13回・第14回で繰り返し述べたとおり、
**AI は物理の代替ではなく、物理計算の高速化と補完**である。

**2. すべては繋がっている**

第3回の $P = (V_sV_r/X)\sin\delta$ という 1 つの式が、
潮流計算のヤコビアン（第5回）、等面積法（第7回）、
高速デカップル法（第5回）、直流法潮流（第4回）、
そして電力市場の価格形成（第14回）にまで繋がっていた。

**基礎を疎かにしないこと。** それが応用の質を決める。

**3. 制約は 1 つではない**

第15回の総合演習で見たとおり、
再エネの導入可能量は電圧・容量・N-1・慣性・周波数・最低出力という
**複数の制約の中で最も厳しいもの**が決める。
1 つの制約だけを見て「まだ入る」と判断してはならない。

**4. 現場には答えのない問題がある**

低慣性系統の運用、再エネの出力抑制の是非、AI の責任の所在。
